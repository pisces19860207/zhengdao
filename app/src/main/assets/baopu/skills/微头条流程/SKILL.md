# 微头条流程：先看近期热点，再按依据动笔

适用：用户说「写完这批微头条」时按固定流程走。

1. 先联网搜近期热点，记下每条的链接与日期；选题从这些近期结果里来。
2. 读人设与知识库，把这次要用到的条目连同出处记下（文件与行号）；依据里每条都要能点开看原文。
3. 读 产物/台账.md 只用于查重：这批题材与已发过的对照，写过的不再列；台账不当选题来源。
4. 出一张题材与写法建议卡：每条给题材方向、写法要点、推荐理由；卡面顶部一行列出依据，推荐的两三条在卡上标出来。
5. 用户从卡上选定几条后开写，没选定的一律不动；依据为空、或依据指向的条目已不在，就不出卡，先补读人设与知识库。
6. 写完一篇落一篇：文件放 产物/ 目录，文件名带日期与序号；每落一篇，台账末尾加一行：日期、题材、文件名，状态列记 ☐（未发）。
7. 收尾报一句：这批落了几篇、还缺哪几条、台账新增了几行。
