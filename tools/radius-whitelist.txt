# 规约（第七十批 · UI 第六批，2026-10-20）：
#   · 8 档裸值（4/6/8/10/12/14/16/24）默认**报红**，只有两种理由可以进白名单：
#       「待收编」＝文件正被别的批次占用（63/68），合入 main 后必须换成令牌并**删掉这一行**；
#       「语义位不同」＝值虽然撞在 8 档上，但那一位的语义不是 Radius.kt 定义的层（例：对话框用了 16dp）。
#   · ≥50（`50` 百分比式 / `999.dp`）是**胶囊**，门禁自动放行，不需要写在这里。
#   · **总数封顶**（2026-10-29）：MAX_WHITELIST_ENTRIES＝24，只降不升；超一条就红。
#   · **「待拍板」条目**必须带日期（YYYY-MM-DD），且总数 ≤ MAX_PENDING_ENTRIES＝20；
#     下一批清理时（语义拍板 → 换令牌）连条目带分档数一起往下调。
#   · 20/22/28 这类自定义值必须写清「为什么不是 8 档之一」。
#   · 白名单条目一旦没有对应裸值，门禁会打「过期」提示 ⇒ 当场删行，不许留僵尸条目。
