安卓上的 AI agent 运行环境：内置助手「抱朴」，也有真 Debian 终端。

一个 APK 装完就用，免 root、不敲命令。抱朴会读写工作区里的文件、查网页、看图改图、写东西；玄览是它的眼睛——在 App 内打开网页，把页面交给它看；需要跑真实命令时，切到逍遥的终端。

**门槛**：Android 16（API 36）＋ arm64 手机。不符合装不上。

**下载**：[GitHub Releases](https://github.com/pisces19860207/zhengdao/releases)，当前版本 v2.2.0。

**不用装**：Termux、Shizuku，不需要 ADB，也不用连电脑。

## 系统要求

- **Android 16（API 36）或更高版本**
- **arm64-v8a** 架构设备（只提供 arm64 单架构包）
- 已在荣耀 Magic 5 Pro（MagicOS 10.0.0.175 / Android 16，`PGT-AN10`）上完成实测；其他机型与系统版本未逐一验证

> 0.8.0 起 `minSdk` 就是 36，所以当前版本在 Android 15 及以下装不上；更早的 0.7.x 曾支持 Android 10，但早已停止分发与维护，不作为安装路径。

## 四个 Tab

证道只有四页，各管一件事：

| Tab | 定位 | 能干什么 |
|---|---|---|
| 抱朴 | 内置 agent | 对话；读写与搜索工作区文件，看图、改图、多图一起发，读网页，整理资料库、建本地索引，排计划，攒技能；写小说、续写、改稿；写的代码只在玄览里显示 |
| 逍遥 | 终端 | Debian 13 环境，需要 shell 的时候用 |
| 玄览 | 浏览器 | 抱朴的眼睛：在 App 内打开网页，把页面交给它看；它也能点按、翻页；本地代码与页面只显示、不执行 |
| 怡然 | 安装与体检 | 安装第三方 Agent（Hermes / Claude Code / Codex / AGY CLI，都不是预装，装了才有）与运行环境，做环境体检 |

抱朴和玄览是一对：一个动手，一个负责看；页面从玄览交给抱朴，产出落回工作区。抱朴不碰 shell、不起子进程，只在工作区里活动；要动系统的事，去逍遥。

## 让它动手

**整理**。设定集、参考图、笔记散在手机里，把分类和命名规则说清楚，让抱朴归进资料库。它先列清单或方案，你点头才动；一次只做一件，做完告诉你动了哪些文件。资料库可以建本地索引，提问时回答带来源和行号；断网也能用。

**看与改**。网页、图片都能交给它：总结、摘录、缩放、裁剪、转格式。页面在玄览里打开，可以让它点按、翻页，也可以由你指定看哪页；图片可以一次发多张。

**写**。大纲给它，一章一章写；写完接着续，旧稿不满意就贴回去让它改。产出是工作区里的普通文件，文件管理器直接能打开。写代码也一样，只是代码只展示、不执行。

## 会攒，但不自作主张

抱朴会沉淀技能、提炼记忆，每一步都要你点头：

- **技能**先当草稿，默认不进它的视野；用满 3 次才转正。写技能要过确认卡，写前自动备份，能恢复上一版。
- **记忆**在会话结束时提炼成候选，你点「记住」才落盘，点「不记」就丢弃。
- **人设**分三层：核心只读；**全局层和项目层都会随会话进化**——它会提提案，你批准才落盘。全局层跟着 App 走，换工作区不丢；项目层跟着工作区走，换项目不串味。
- **全局技能**它不许改，只能提议；要改得你自己在设置里动手。

一句话：它会变，但不会背着你变。

## 重在哪

- **运行时在 App 里**：agent 循环、工具、步数预算、上下文压缩、被杀续跑，都是自己实现的一份，不是把桌面 CLI 包一层。
- **治理在运行时层**：工具按组开关、写删改要确认、只能在 workspace 活动、单次任务有步数上限、压缩有阈值——拦得住，不靠提示词自觉。
- **进化有闭环也有闸**：技能从草稿到转正、记忆从候选到落盘、人设从提案到生效，都走「先备份、再确认、可回滚」这一条路。

三件事合起来，才是「重 harness」：不是工具多，而是每个动作都有边界和留痕。

## 装与用

1. 从 [Releases](https://github.com/pisces19860207/zhengdao/releases) 下载 APK，在手机上直接安装。每个包都带签名，App 内「关于」页会标明是官方包还是被重新打包过的包。
2. 首次打开，先在一页里把权限逐项授完；要到怡然做一次环境体检，用逍遥则在这里安装 Debian 环境（约 200 MB，需联网）。
3. 用抱朴之前，到设置里填模型服务商：OpenAI 兼容或 Anthropic 接口格式，填你自己的地址和 Key。
4. 怡然给的是安装卡，不是预装：Hermes / Claude Code / Codex / AGY CLI 都要你自己点安装，装好才有；不想装就不装。
5. 抱朴读写的文件都在工作区里（默认手机 `Download/证道`，可在设置里改）。卸载证道，工作区的文件还在。
6. 更新：App 内可检查 App 与组件更新；环境包更新只下差分补丁。

历史版本与发布记录见 [Releases](https://github.com/pisces19860207/zhengdao/releases)。

## 网络与保活

证道什么时候联网，逐条列清：

- **抱朴**：把你的对话内容、以及你让它读的文件内容，发给你在设置里选定的模型服务商（OpenAI 兼容 / Anthropic）。
- **玄览**：访问你打开的网页；渲染走系统 WebView。
- **怡然**：下载运行环境与组件。

除此之外，证道本身不收集用户数据。Key 只存本机。抱朴不自带模型，无网时用不了；逍遥装好环境后，终端可以离线用。

用代理 App（Clash、v2rayNG 一类）时：要开 VPN 模式；开了「分应用代理」的，必须把证道勾进去——连不上多半是这个原因。仍不行可在设置里的「高级」手填代理地址。

安卓会回收后台应用。跑长任务时，把证道留在前台，或在多任务里锁住、电池优化设为不优化。真被杀了现场也不丢：重新打开，逍遥的终端会话会自动恢复；抱朴这边，跑着再发消息会排队，切走或退后台也会继续跑。

## 隐私

- Key 只存本机，不上传。
- 抱朴发出去的只有一样东西：你的对话，以及你让它读的文件；收件方是你自己选的模型服务商。它不主动翻你的文件——你让它读哪份，哪份才会发出去。
- 玄览访问的网页、怡然下载的组件，就是上一节列的那几条，没有别的。
- ⚠️ **终端不是安全沙箱**：逍遥里的进程与 App 同一个 Android UID、同一个内核与网络栈，能读写 App 能读写的文件。只运行你信任的命令。

## 已知限制

- 只支持 Android 16（API 36）＋ arm64，且只在一台真机上做过完整验证；其他机型与系统版本未逐一测试。
- 抱朴会写代码，但代码只在玄览里显示、不执行。想在手机上跑代码，去逍遥；两条线互不越界。
- 抱朴不碰 shell、不起子进程；要动系统的活，它做不了，也不去做。
- 无网时抱朴不可用；长任务受后台回收影响，见「网络与保活」。
