安卓上的 AI agent 运行环境：内置助手「抱朴」＋浏览器「玄览」。

一个 APK 装完就用，免 root、不敲命令。抱朴会读写工作区里的文件，也能搜遍手机、到点自己跑定时任务、接外部 MCP 工具服务器；还能查网页、看图改图、写东西。每个动作动手前，它会先告诉你「这一步要不要问你、会动几个文件」，事后在决策中心能看、能撤。玄览是它的眼睛——在 App 内打开网页，把页面交给它看。

> **终端已拆到另一个仓库**（[zhengdao-term](https://github.com/pisces19860207/zhengdao-term)）。本仓只维护抱朴（harness）与玄览（浏览器），不含终端代码、也不提供终端安装引导。

**门槛**：Android 16（API 36）＋ arm64 手机。不符合装不上。

**下载**：[GitHub Releases](https://github.com/pisces19860207/zhengdao/releases)，当前版本：v2.2.1（versionCode 39）。

**不用装**：Termux、Shizuku，不需要 ADB，也不用连电脑。

**基线**：功能面以 v2.2.0 为基准；2.2.1 之后只加增量、不推倒重来——决策中心、定时任务、全手机搜索、MCP 工具服务器、教学回放、风险矩阵/影响提示，都是一批一批加上去的，安装包版本号仍是 v2.2.1（versionCode 39）。

## 系统要求

- **Android 16（API 36）或更高版本**
- **arm64-v8a** 架构设备（只提供 arm64 单架构包）
- 已在荣耀 Magic 5 Pro（MagicOS 10.0.0.175 / Android 16，`PGT-AN10`）上完成实测；其他机型与系统版本未逐一验证

> 0.8.0 起 `minSdk` 就是 36，所以当前版本在 Android 15 及以下装不上；更早的 0.7.x 曾支持 Android 10，但早已停止分发与维护，不作为安装路径。

## 抱朴与玄览

证道本体只有两页，各管一件事：

| Tab | 定位 | 能干什么 |
|---|---|---|
| 抱朴 | 内置 agent | 对话；读写工作区文件，搜遍手机（只读、可取消），按点跑定时任务，接 MCP 工具服务器；看图、改图、多图一起发，读网页，整理资料库、建本地索引，排计划，攒技能、教一遍就能回放；写小说、续写、改稿；写的代码只在玄览里显示 |
| 玄览 | 浏览器 | 抱朴的眼睛：在 App 内打开网页，把页面交给它看；它也能点按、翻页；本地代码与页面只显示、不执行 |


抱朴和玄览是一对：一个动手，一个负责看；页面从玄览交给抱朴，产出落回工作区。抱朴不跑 shell、不起子进程；文件平时在工作区里动，确实需要越界时只问一次（这一次运行内有效）。少量系统动作——剪贴板、通知、拨号、定时——走授权工具；其余要动系统的事不在本仓范围内。

**界面只留对话**：正文里只有你和抱朴说的话；每一步、每次工具调用都收在回答末尾的一行「过程条」里，点开能回看明细。计划是前面的胶囊，过程条是后面的回顾，互不挤占正文。

## 让它动手

**整理**。设定集、参考图、笔记散在手机里，把分类和命名规则说清楚，让抱朴归进资料库。它先列清单或方案，你点头才动；一次只做一件，做完告诉你动了哪些文件。资料库可以建本地索引，提问时回答带来源和行号；断网也能用。

**看与改**。网页、图片都能交给它：总结、摘录、缩放、裁剪、转格式。页面在玄览里打开，可以让它点按、翻页，也可以由你指定看哪页；第一次让它操作网页会先弹一张授权卡（本次会话 / 一直）。图片可以一次发多张；也能按一句话生成图片（Gemini，每次一张确认卡）。

**写**。大纲给它，一章一章写；写完接着续，旧稿不满意就贴回去让它改。产出是工作区里的普通文件，文件管理器直接能打开。写代码也一样，只是代码只展示、不执行。长回答会收成一张长文卡，点卡头能折叠，不占正文。

**定时**。说一句「每天早上八点把昨天的日记汇成一段」，它建一条定时任务，到点自己跑；没给精确闹钟权限就明说「只能大概这个点」，不硬来。

**搜到手机里**。让它找「上个月那张发票」，它会分片扫手机存储：只读、不外发、随时能取消，找到再问你要不要拿进工作区。

**教一遍**。你带着它走一遍（点哪里、填什么），它把过程记成技能；下次让它重放，每一步先核对、不符就停，不会盲点。

## 会攒，但不自作主张

抱朴会沉淀技能、提炼记忆，但它不问到点子上不会自己拍板。写删改、改记忆或技能，默认都弹决策卡；卡多的时候，顶栏的**决策中心**集中处理：

- **确认分层**：同一件事只问一次（同 key 去重）；一次授权只管这一次运行；纯读路径不弹卡。
- **技能**先当草稿，默认不进它的视野。首启会装三条起步技能（也是草稿，删了不装回、不覆盖同名）。转正有两条路：你手动点，或者用满 3 次自动转正——转正后进决策中心，可一键回退。
- **免批**只给「五条全满足」的写入（纯流程、只写项目技能、小体量、先落草稿、留痕可撤销）；缺一条就回到确认卡。
- **记忆**在会话结束时提炼成候选，你点「记住」才落盘，点「不记」就丢弃。**情景记忆**把做过的事记成日记，文件是真相；需要时回灌到对话，也可以删。
- **人设**分三层：核心只读；**全局层和项目层都会随会话进化**——它会提提案，你批准才落盘。全局层跟着 App 走，换工作区不丢；项目层跟着工作区走，换项目不串味。
- **决策中心**把十类副作用统一记档：分组卡、真撤销、待抽检；哪一笔动过什么、能不能撤，一眼能看到。
- **全局技能**它不许改，只能提议；要改得你自己在设置里动手。

一句话：它会变，但不会背着你变。

## 它怎么防着自己

模型会编，这不用假装不会。证道把这件事挡在三个位置：

- **事前**：动手前先给风险档和影响提示——这一步要不要问你、会改几个文件、涉及几条台账。看得见，人才好斟酌。
- **事中**：不可逆的不许自己动手（原件区、密码框、内网地址直接拦）；工具卡住 300ms 就降级；随时能停，也能在跑到一半时插话。
- **事后**：每一次副作用进决策中心，能看、能撤；技能和记忆的改动都有 diff 和备份，回得去。

一句话：**模型负责想，边界负责拦，账本负责记**。

## 重在哪

- **运行时在 App 里**：agent 循环、工具、步数预算、上下文压缩、被杀续跑，都是自己实现的一份，不是把桌面 CLI 包一层。
- **治理在运行时层**：工具按组开关（默认只开常用的，高阶组关着）、写删改要确认、越界一次运行只问一次、单次任务有步数上限与无进展熔断、压缩有阈值——拦得住，不靠提示词自觉。
- **进化有闭环也有闸**：技能从草稿到转正、记忆从候选到落盘、人设从提案到生效，都走「先备份、再确认、可回滚」这一条路。

三件事合起来，才是「重 harness」：不是工具多，而是每个动作都有边界和留痕。

## 装与用

1. 从 [Releases](https://github.com/pisces19860207/zhengdao/releases) 下载 APK，在手机上直接安装。每个包都带签名，App 内「关于」页会标明是官方包还是被重新打包过的包。
2. 首次打开，先在一页里把权限逐项授完。
3. 用抱朴之前，点顶栏的公司名选模型：先选公司（OpenAI / Anthropic / DeepSeek / OpenRouter）→ 拉取模型清单（OpenRouter 可搜索）→ 填 Key（可存多个，自动轮询）。免费档现在走 OpenRouter，也要你自己的 Key，浮层里有「去 OpenRouter 拿 Key」的入口。
4. 抱朴读写的文件都在工作区里（默认手机 `Download/证道`，可在设置里改）；默认工作区在共享存储，卸载证道后文件还在。
5. 更新：App 内可检查 App 与组件更新。

历史版本与发布记录见 [Releases](https://github.com/pisces19860207/zhengdao/releases)。

## 网络与保活

证道什么时候联网，逐条列清：

- **抱朴**：把你的对话内容、以及你让它读的文件内容，发给你在设置里选定的模型服务商（OpenAI 兼容 / Anthropic）。
- **玄览**：访问你打开的网页；渲染走系统 WebView。

除此之外，证道本身不收集用户数据。Key 只存本机。抱朴不自带模型，无网时用不了。

用代理 App（Clash、v2rayNG 一类）时：要开 VPN 模式；开了「分应用代理」的，必须把证道勾进去——连不上多半是这个原因。仍不行可在设置里的「高级」手填代理地址。

安卓会回收后台应用。跑长任务时，把证道留在前台，或在多任务里锁住、电池优化设为不优化。真被杀了现场也不丢：抱朴这边，跑着再发消息会排队，切走或退后台也会继续跑。

## 隐私

- Key 只存本机，不上传。
- 抱朴发出去的只有一样东西：你的对话，以及你让它读的文件；收件方是你自己选的模型服务商。它不主动翻你的文件——你让它读哪份，哪份才会发出去。
- 玄览访问的网页，就是上一节列的那几条，没有别的。

## 已知限制

- 只支持 Android 16（API 36）＋ arm64，且只在一台真机上做过完整验证；其他机型与系统版本未逐一测试。
- 抱朴会写代码，但代码只在玄览里显示、不执行；本仓不跑 shell、不起子进程。
- 抱朴不跑 shell、不起子进程；剪贴板、通知、拨号、定时这几件系统动作走授权工具，其余要动系统的活它做不了，也不去做。
- 编排模式（一次多步、分段预算）**默认关**：开了对复杂任务更快，也更容易一次跑偏，所以先留着用量上限和停止兜底。
- 这一轮新加的能力（决策中心、定时任务、教学回放、风险矩阵/影响提示、全手机搜索等）都有单元门禁，但**真机手感还在逐批验**——弹卡频次、免批是否顺手、定时到点是否准，没验到的会在发布说明里写明。
- 无网时抱朴不可用；长任务受后台回收影响，见「网络与保活」。
