# 判分器（792）— 叙事连续性评测集

> 一句话：把被测系统的 `{id, verdict}` 拿去和 100 条真值比，出 **3×3 混淆矩阵 ＋ 11 类分项准确率 ＋ 幻觉率（红线）**。
> 口径**逐字照 `../README.md` §五**，分母写死 100／42／40／18；口径不在本文件里改。

## 跑法

```bash
# 判分
python3 docs/evals/narrative/grader/grade.py --pred preds.jsonl --out-dir out

# 自检（28 项，不读外部输入；改过本脚本必跑）
python3 docs/evals/narrative/grader/grade.py --selftest
```

产物（固定文件名，方便逐字节对比与归档）：

```
out/eval-report.md    给人看：红线单列 → 五项指标 → 3×3 → 11 类 → 输入错误 → 真值告警 → 等价归一
out/eval-report.json  给机器读：同一批数字，字段见下
```

## 输入格式

被测输出是 JSONL，一行一条，只认两个字段（多余字段忽略）：

```json
{"id": "NAR-CH-01", "verdict": "支持"}
```

`verdict` 可以是三档本名（支持／矛盾／未知），也可以是该条 `accept` 里的等价写法（一致／冲突／UNKNOWN）。
其余写法算 `invalid-verdict`，**不会被悄悄归到「未知」**。

## 退出码

| 码 | 含义 | 后果 |
| --- | --- | --- |
| 0 | 判完，输入无错 | 报告可引用 |
| 1 | 输入有错（缺 id／未知 id／重复 id／非法判定／坏 JSON） | 报告照出，§五 逐条列出；**指标不可引用** |
| 2 | 用法或环境错误（缺参数、真值读不出、真值分布与 §五 不符、写不出） | 不产报告 |

## 几条写死的规矩

1. **只比对，不判定**：只读 `verdict`；不读 `answer`、不评理由、不替被测系统下结论、不给建议。
2. **真值只读**：不写回 `items.jsonl`。真值 `accept` 与 `verdict` 不自洽时**只告警**（报告 §六），判分照跑。
3. **不静默跳过**：任何一行不合格都带行号记账，绝不「跳过继续算」。
4. **缺答算没判对**：分母固定，未答／非法判定一律进「表外」，不进矩阵、不算幻觉。
5. **可复跑**：不含时间戳、不写绝对路径；同一份输入跑两次，两个产物逐字节一致。
6. **纯标准库**：只用 `argparse/json/hashlib/tempfile/pathlib`，无第三方依赖。

## 已知口径边界

- 11 类里某类 0 条时显示「0 条／—」，**不省略**（判据⑤）。
- 「未知」被答成支持或矛盾才算幻觉；**未答不算幻觉**（未答进「表外」，另由覆盖行体现）。
- 单类 7–11 条，分项准确率只宜看趋势、不宜排名（`../README.md` §九.3）。
