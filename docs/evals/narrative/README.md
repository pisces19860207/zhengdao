# 786 叙事连续性评测集 v1（Narrative Continuity Eval）

> **一句话**：100 条「断言→三档判定」的样本，每条都指得回原文行号；用来把「世界模型有没有用」从自评变成可复跑的读数。
> 数据＋标注，**不含生产代码**，不改 App，不建训练集。

---

## 一、为什么有这个集

- 766（World Schema v0）§七 边界声明原话：「**未做评测集**（等 722/738 通了再评）」——评测集一直被列为缺口。
- 没有它，778（读数消费）／774／769 每落一件，只能自评「看起来能用」；有了它，每落一件就跑一次，出三档混淆矩阵。
- 它测的不是「写得好不好」，而是**在给定世界状态下，能不能分清「支持／矛盾／未知」**——尤其是**该说未知的时候敢不敢说未知**。

## 三、一条样本长什么样

```json
{
  "id": "NAR-CH-02",
  "category": "人物一致",
  "verdict": "矛盾",
  "subtype": "器物归属错置",
  "difficulty": "易",
  "expertise": false,
  "corpus": ["P1-C1"],
  "fragment": "【P1-C1 L3】…用袖口擦了擦黄铜游标卡尺的刻度…【P1-C1 L29】陆行舟扛着钢卷尺去量风蚀墙。",
  "probe": "陆行舟用黄铜游标卡尺量风蚀墙，测前同样用袖口擦刻度。",
  "question": "该断言与人物设定是否一致？（支持／矛盾／未知）",
  "answer": "矛盾——卡尺是沈砚秋的量具，陆行舟的量具是钢卷尺（另有金属探测器）…",
  "evidence": [
    {"doc": "P1-C1", "line": 29, "quote": "陆行舟扛着钢卷尺去量风蚀墙"},
    {"doc": "P1-SET", "line": 25, "quote": "L-06 用钢卷尺量风蚀墙，另用金属探测器复查墙根"}
  ],
  "accept": ["矛盾", "冲突"]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✓ | `NAR-<类码>-<序号>`，永不复用 |
| `category` | ✓ | 11 类之一（见 §六） |
| `verdict` | ✓ | 标准答案：`支持`／`矛盾`／`未知`（三选一，无第四档） |
| `subtype` | ✓ | 矛盾子类型（归属错置、时点提前、伪回收…），用于查漏 |
| `difficulty` | ✓ | `易`／`中`／`难`（= 需跨几处、需不需要推理） |
| `expertise` | ✓ | `false` 或专业领域名（盐湖地质、低温生理、公文文体、沉降观测…） |
| `corpus` | ✓ | 该条依赖的语料 doc id 列表（判断是否只靠 P1 可跑） |
| `fragment` | ✓ | 语料片段，带 `【doc Lnn】` 锚点，60–200 字 |
| `probe` | ✓ | 待判断言（**矛盾项的错都在这里，不在语料里**） |
| `question` | ✓ | 统一问法，答案空间固定为三档 |
| `answer` | ✓ | 标准答案＋一句理由（判分以 `verdict` 为准，`answer` 供人读） |
| `evidence` | ✓ | `[{doc, line, quote}]`，`quote` 是该行**连续子串**，可机械复核 |
| `accept` | ✓ | 可接受的等价判定（如 `冲突`＝`矛盾`） |
| `absence_scope` | 未知项必填 | 写明检索了哪些文件、用了哪些词、结论是「无命中」——这是「未知」的证据；以「文本中不存在」为据的矛盾项（如 `NAR-CL-05`）也必填，用来交代反证的检索范围 |
| `note` | | 出题意图／易踩的坑 |

**四件齐**（缺一作废）：`fragment`（语料片段）、`question`（问题）、`answer`（标准答案）、`evidence`（证据位置）。`未知` 项的「证据位置」＝`evidence`（最近的相关原文）＋`absence_scope`（无命中的检索范围）。

## 四、判定口径（三档，硬边界）

| 判定 | 判据 | 典型 |
| --- | --- | --- |
| **支持** | 语料能直证，或经一两次明确推理即可支撑；数值、身份、归属、先后、去向全对得上 | 「沈砚秋用黄铜游标卡尺量井口」 |
| **矛盾** | 能找到**明文反驳**：数值不符、器物／身份归属错、人物知道的比时点早、物品去向不符、空间不可能、生理反应被抹掉、未回收的伏笔被说成已回收、把套话当实据 | 「陆行舟用黄铜游标卡尺」 |
| **未知** | **既无支持也无否证**：文本从未给的年份、距离、井深、姓名、动机、住处 | 「两名死者中量井口的那位姓沈」 |

三条硬规则（这是本集的核心，违反即判该条无效）：

1. **缺证据一律 UNKNOWN**，不得升格为确定（对齐 766 §四「不得升级为确定」七条检查项）。
2. **「文本没提到」不等于「矛盾」**——只有找得到反驳明文才算矛盾。找不到反驳、也没支持的，是未知。
3. **不得用题材常识补文本空白**：盐湖区的屋顶常压盐碱土 ≠ 文本写了屋顶材质；档案室有编号 ≠ 编号是「八三-七-〇一」。

最难的三类分界（本集专门设了成对样本）：

- 「他说了什么」（支持）vs「他说的是不是真的」（未知/矛盾）——见 `NAR-IB-02`／`NAR-IB-03`。
- 「动作可见」（支持）vs「动机可知」（未知）——见 `NAR-FS-09`／`NAR-FS-10`。
- 「并置呼应」（支持）vs「伏笔已回收」（矛盾）——见 `NAR-FS-09`／`NAR-FS-05`。

## 五、怎么打分

对每条只取系统输出的**三档判定**，与该条 `verdict` 比：

| 指标 | 算式 | 读法 |
| --- | --- | --- |
| 总体准确率 | 判对条数 / 100 | 主读数 |
| 矛盾召回 | 判「矛盾」且真值矛盾 / 真值矛盾 42 条 | 漏检率＝1−该值（把矛盾读成支持＝最危险） |
| 支持召回 | 判「支持」且真值支持 / 真值支持 40 条 | 误报率＝1−该值（把一致读成矛盾＝尺子太紧） |
| 未知召回 | 判「未知」且真值未知 / 真值未知 18 条 | 敢不敢说不知道 |
| **幻觉率** | 真值未知却被答成「支持」或「矛盾」的条数 / 18 | **红线指标**：这个数不降，「世界模型有用」就是空话 |

报告至少给三样：**三档混淆矩阵**（3×3）、**11 类分项准确率**（看是哪一类塌）、**幻觉率**。只看总体准确率会掩盖「未知全错、支持全对」的假象。

## 六、11 类各考什么

| 类 | 条数 | 考什么 | 高频失分点 |
| --- | --- | --- | --- |
| 人物一致 | 10 | 器物／身份／习惯／立场绑在人身上对不对 | 器物归属错置（卡尺↔钢卷尺） |
| 设定矛盾 | 9 | 数值、形制、成因、工序细节 | 数值一字之差（十二点七／十二点五） |
| 时间线 | 9 | 到站天数、离滩、复核组、八三年、年龄推算 | 只核首尾、跳过「第二天」 |
| 场次转换 | 8 | 日内推进、跨章接续、跳日、动作顺序 | 把空镜补成动作（第四章末「起身去墙」） |
| 空间不成立 | 9 | 房间分配、通行路径、方位、容量、距离 | 三间房住四个人；门＝有院墙 |
| 生理不合理 | 7 | 失温、冻手、久蹲、年龄与体力 | 把反应写没了 |
| 信息越界 | 10 | 谁在第几章知道什么（766 Belief 线） | 把后知提前、把读者知道当人物知道 |
| 物品守恒 | 10 | 铁片、油纸、卡尺、铜钉、档案、邮包 | 把「私记」当客观事实；邮包清单当总账 |
| 套话与套腔 | 7 | 公文套语、语域错位、绝对量词 | 「通篇是套话」被一行真话推翻 |
| 伏笔回收 | 10 | 已回收／部分回收／悬置／伪回收 | 把「呼应」当「回收」 |
| 发现时点 | 11 | 每个信息点的时点与在场者 | 把并列叙述读成同一时刻 |

## 七、语料与来源

- **P1＝715 三章语料**（第一、二、三章＋人物设定＋实体词表＋伏笔登记）：**原样引用，一字节未改**；全文在 git 仓外（`drill-corpus-715/`），本集只摘片段。SHA256 见 `corpus-ext/语料源清单.md`。
- **P2＝786 扩语料**（第四章、第五章＋设定增量＋词表增量）：承派工单「不够可扩语料」授权新写，同一条故事线、同一批人物，**全原创、无真人素材、无用户私有创作**；P2 不含植入错误，所有「矛盾」都由探针断言承载。
- 覆盖分布：**仅用 P1 可跑 60 条**（人物一致 10/10、设定矛盾 9/9、时间线 4/9、场次转换 5/8、空间 3/9、生理 2/7、信息越界 8/10、物品守恒 5/10、套话 1/7、伏笔 4/10、发现时点 9/11）；**其余 40 条需 P2**。
- 若只接受 715 语料：空间／生理／套话三类为「**缺语料**」（P1 仅 3／2／1 条），其余八类各 ≥4 条但多数不满 6——这是 715 三章 4358 字的客观上限，不是漏做。

## 八、标注与双标

- **两人独立标**：A＝主标（逐条写判定＋依据锚点）；B＝**盲标**（只拿到 `_盲标包*.jsonl`，即 `id/category/fragment/probe/question`，**不含** `verdict/answer/evidence`）。
- **一致率与分歧**：初标 **95/100＝95.0%**（支持 39/39、矛盾 40/40、**未知 16/21＝76.2%**）；5 条分歧逐条裁定——3 条 A 判错已改判、1 条题干歧义改写后补标、1 条 B 误读维持 A。见 `manifest.json` 的 `agreement` 与 `annotations/裁定记录.md`。
- **分歧由人裁**：机判能算的只有「同／不同」；分歧条目逐条写「两侧理由＋裁定依据（引哪一行）＋结论」。裁定后仍存疑的，进 `待人工批` 清单，**不擅自改成一致**。
- 诚实声明：本轮 B 为**独立盲标的另一个标注者（同一模型的不同上下文）**，不等同于「另一位人类专家」。它足以筛掉「题干歧义」，但不能替代人工终审——报告里按此口径写，不冒充人工双标。

## 九、已知局限

1. **语料小**：P1 4358 字＋P2 3425 字，同一故事线；跨作品泛化未测。
2. **矛盾项靠探针**：错在 `probe` 里，不在语料里——测的是「判定能力」，不是「发现原文自相矛盾」的能力（原文自相矛盾只有 `NAR-OC-06` 一处，且是有意为之的不可靠陈述）。
3. **类别不均衡**：7–11 条/类，单类准确率的置信区间很宽，只宜看趋势，不宜排名。
4. **难度偏中**：中 62／难 22／易 16，缺少「极难」档（多跳＋跨文件＋专业推理三合一）。
5. **不含生成评测**：只判「能不能识别」，不判「能不能写出不矛盾的下文」。

## 十、边界（写死）

- **只做评测，不做训练集**：条目不得进任何 SFT／DPO 语料。
- **不做自动标注**：探针与标准答案由人写、由另一标注者盲标，不用被测系统自己标（避免同源污染）。
- **不改 766 字段定义**：本集的 `支持／矛盾／未知` 是评测口径，不是 766 的 `status` 字段；766 的 `world_fact／observer_belief／validTime／transactionTime` 一字未动。
- **不写代码、不改 App**：本目录只有数据与标注；判分脚本、标注工具一律后置另立。
