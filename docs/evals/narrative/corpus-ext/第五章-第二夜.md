# 第五章 第二夜

那一夜的敲声，沈砚秋听得比第一回清楚。不是风，风是连成一片的；那声音有间隔，三下，停，再三下。她从木板床上坐起来，披了棉袄，摸黑往东头去。三间平房连成一排，门都朝南，中间那间是穿堂，从西头到东头，非得从中间的门底下过。她走到穿堂口就停住了。

东头那间的门虚掩着，缝里漏出一道黄光。老贺坐在桌边，背对着门，手里捏着一枚小小的铜钉，一下，一下，敲在三足铜蟾蜍的背上。铜的声音很短，敲完就没了，像往水里丢石子，连个回响都不肯给。

沈砚秋站在穿堂的阴影里，看了很久。她想起自己第一天到站时问过这声音，老贺只说“听见了就当没听见”。她没有推门。她知道自己一推开，那扇门就会关上很多年。

她退回西头，把棉袄压在被子上面，坐着等到天亮。

第二天早上，风小了些。她照旧六点去井上，擦卡尺的时候，袖口蹭不掉刻度上的霜，她哈了一口气，用指腹化开，才看清那个数：十二点七。回来时老贺已经在门槛上坐着，搪瓷缸搁在脚边。

“贺站长，”她站在他面前，“夜里的声音，是铜钉敲的？”

老贺抬头看了她一眼。“你听见了。”

“听见了。”

他把缸端起来，喝了一口，水线还是停在裂纹下面。“听见了就听见了。”他说完这句，就不再开口。沈砚秋站了一会儿，转身进屋。她没再问——问也没有用，他愿意说的时候，自己会说。

上午，苗小满把昨夜写成的材料拿给她看。一共两页半，标题是《关于白碱滩水文站历史遗留问题复核工作的情况报告》。第一段写：“接局领导指示后，我组高度重视，迅速行动，加强领导，狠抓落实，深入一线，掌握实情，确保不留死角、不走过场、不搞形式。”第二段写：“针对历史遗留问题，我组坚持问题导向，举一反三，标本兼治，形成合力，压实责任，为下一步工作打下坚实基础。”

沈砚秋把两页半读完，抬头问：“底座挖了没有？”

“还没有。”苗小满说，“风太大，等风停了再挖。”

“那这上头写的‘掌握实情’，”她把纸放回桌上，“实情是什么？”

苗小满愣了愣，说：“实情就是……我们来了，我们看了，我们了解了情况。”

老贺在门口听见了，笑了一下。那笑很短，像咳。“写得好。”他说，“一个字也不像这滩上的话。”

中午，盐场的邮车送来一个邮包，是陆行舟寄的。牛皮纸包着，封口的浆糊开了，绳子还系着。沈砚秋拆开，里面是一份测量报告的副本，和一张对折的信纸。信写得很规矩：“沈工：离滩后一切顺利，现将有关情况报告如下。一、风蚀墙墙根金属底座的位置与尺寸，已按原记录复核，误差在允许范围内。二、补充档案已交档案科，请领导审示。三、白碱滩冬季风大，井台请注意防冻。此致敬礼。”

信纸的最后一行，字忽然挤在一起，像临时加上去的：“那两个名字我抄下来了，可我不敢寄，怕半路丢。”

沈砚秋把信翻过来，背面是空的。她又数了一遍邮包里的东西：报告副本一份，四页；信纸一张；没有别的。她在站里见过陆行舟那本蓝皮笔记，知道他有把东西夹在纸里的习惯。她把手伸进牛皮纸包里摸了摸，摸到一角硬纸，抽出来，是半张空白的地形图纸，边上撕得不齐。

下午，曹德海把四份复印件和硬皮簿子收回铁皮箱，换成一根新铅封，铅上打的号是“水档-83-07-补”。他把箱子推到苗小满面前：“你抱着，路上不许离手。”

“请领导放心，”苗小满说，“我一定做到件件有落实、事事有回音。”

沈砚秋在旁边收拾卡尺。她的手冻得发僵，把卡尺合拢的时候，两个量爪碰在一起，响了一声，很轻，像昨夜铜钉敲在蟾蜍背上的那一声。她停了一下，把卡尺放进工装口袋，按了按。

傍晚风停了。盐湖结了一层薄冰，白得发青。老贺从怀里摸出那枚铜钉，在掌心掂了掂，又揣回去，谁也没给。

第二天上午，复核组的车走了。苗小满上车前还在说“感谢配合、保持联系、后续跟进”，说到一半被风吹得咽了回去。车开出去很远，沈砚秋还站在站前的空地上。

她走回井边，蹲下，擦卡尺，量井口。风停了，盐壳不响，整个白碱滩安静得像一张摊开的纸。

“十二点七。”她念出声，记进牛皮封记录本。这是第五十九天。
