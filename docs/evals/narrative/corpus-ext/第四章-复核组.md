# 第四章 复核组

陆行舟离滩后的第十一天，白碱滩入了冬。风还是从盐湖那头刮过来，只是比先前硬，带着冰碴子一样的碎响。沈砚秋照旧六点到七号井，蹲下，擦卡尺。手指头冻得不听使唤，她把袖口在刻度上蹭了三遍，才看清游标压着的那根线——十二点七。

她把这个数记进牛皮封记录本，笔尖在“七”的最后一笔上顿了一下。这是她到站的第五十七天。四十六加十一，她在心里算过一遍，算完又觉得自己无聊。滩上冷得早，夜里的霜把盐壳冻得发脆，一脚踩下去，声音像踩碎一层薄瓷。

上午九点，局里的复核组到了。一台旧越野车停在站前的空地上，下来两个人。前头那个五十来岁，穿呢子大衣，大衣肩上落了一层白霜，他自己伸手掸了两下，才把手递过来：“档案科，曹德海。”后头那个二十出头，戴眼镜，怀里抱着一个铅封的铁皮箱，箱角磕掉了一块漆。

“这是苗小满，办公室的，下来锻炼。”曹德海说。

“沈砚秋。”她握了一下，松开，“住中间那间。”

苗小满把铁皮箱搁在门槛上，先不看箱子，先看人，笑了一下：“沈工，我们这次下来，主要是落实局领导的重要指示，把八三年那件事的历史遗留问题彻底摸清，确保不留死角、不走过场、举一反三。”他顿了顿，又补了一句，“形成合力。”说完自己先点了一下头。

沈砚秋没接话。她听懂了“落实”“摸清”“不留死角”，却没听出他到底要做什么。她侧过身让开路：“水在缸里，自己舀。”

贺长庚从东头出来，站在自家门槛上，没往前走。曹德海快步过去，双手握住他的手，说了几句“老同志辛苦了”“组织上没有忘记”。老贺把手抽回来，在裤子上慢慢擦了一下，说：“墙根底下埋着东西，你们要挖就挖，别踩坏了井台。”

曹德海愣了一下。苗小满已经掏出本子和笔，飞快地记，一边记一边念出声：“老同志反映，墙根有埋藏物，需现场核实。”他念得很顺，像在念一份早就写好的材料。

从站门口到场外的风蚀墙，沈砚秋走过很多回，八百四十步，一刻钟。她领着两个人往那边去的时候，风正好从侧面打过来，把人往盐湖的方向推。苗小满走了不到一半就落在后头，眼镜片上结了一层白，他摘下来擦，擦完戴上，又白。等到了墙根，他的脸已经没了血色，两只手插在袖筒里，说话时牙碰着牙。

“就这儿。”沈砚秋指了指墙根那道横向的沟。

曹德海蹲下去看，看了很久，站起来时扶了一下膝盖，喘了两口气。他五十几岁的人，蹲下去容易，站起来费劲。“底座还在？”他问。

“在。”沈砚秋说，“没人动过。”

“底座上有编号。”曹德海说，“八三年的东西，都打编号。挖出来，对得上，这事就能往下走。”他说完看了一眼苗小满，“记上：待挖，编号待核。”

苗小满记完，又添了一句：“建议下一步加强现场保护，压实责任。”沈砚秋听见“压实责任”四个字，忽然想起老贺说的“不能满，满了就漏”。她没说话，把围巾往上拉了拉，遮住裂了口子的嘴唇。

回站的路上，苗小满从帆布挎包里摸出一台数码相机，给风蚀墙拍了七八张，又给井台拍，给盐湖拍，最后要给沈砚秋拍。她把脸偏开了。“拍墙就行，”她说，“人不用拍。”

中午在中间那间屋里摆开铁皮箱。铅封的封条是一根细铁丝，绕两圈，压着一块铅，铅上打着一串号：水档-83-07。曹德海拿小刀挑开，箱子里是四份复印件、一本硬皮簿子、一个牛皮纸信封。他把信封推到沈砚秋面前：“你报上来的补充档案，局里收了。这里头是回执。”

“那两个名字呢？”沈砚秋问。

“报上去了。”曹德海说，“但要核。户籍、招工表、当年的工资册，一样一样对。对不上，就不能往档案上写。”他停了停，“小沈，我问你一句：油纸上写的东西，你怎么知道是真的？”

沈砚秋想了一会儿。“我不知道。”她说，“我只知道那张纸是从蟾蜍眼里掏出来的，字是老贺的字，年份对得上站里的旧账。至于真假，得你们去核。”

曹德海点了点头，没再问。苗小满在旁边把这一段也记了下来，记完抬头说：“沈工这个态度很好，实事求是，值得肯定。”

下午三点，风更大了。老贺在东头屋里咳嗽，一声接一声，咳到后来弯下腰去，扶着门框才直起来。沈砚秋端了自己那缸水过去，他摆摆手，指了指自己那只搪瓷缸——缸里的水线仍旧停在裂纹以下，一口没多。

傍晚，苗小满在灯下写材料，写了撕，撕了写。沈砚秋从他背后过，看见纸上开头的第一行：《关于白碱滩水文站历史遗留问题复核工作的情况报告》。底下第一句是“高度重视，加强领导”。

那一夜，白碱滩的风没停。沈砚秋躺在床上，听着盐壳在风里响，响得像有人在外头一趟一趟地走。她已经三夜没睡实了，眼皮沉，脑子却清。她想起白天曹德海问的那句“你怎么知道是真的”，翻了个身，把这个问题和风一起压到枕头底下。
