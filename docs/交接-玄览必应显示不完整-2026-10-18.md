## 3. 唯一的坑（审计 §5，务必先看）

半成品里 `hydrate()` 的触发点放在 `AndroidView` 的 `update` 回调里、判断 `measuredHeight>0`。
**`update` 只在重组时才跑，不是「尺寸量出来」时跑** ⇒ 首次加载可能永远等不到 hydrate，表现为「有时能开、按一下主页键又能开」。

**改法（照抄）**：

```kotlin
AndroidView(
    factory = { BrowserTabManager.view() ?: WebView(it) },
    modifier = Modifier
        .fillMaxSize()
        .onSizeChanged { size ->
            if (size.width > 0 && size.height > 0) BrowserTabManager.hydrate(activeId)
        },
)
```
`onSizeChanged` 在尺寸变成非 0 时**必定**回调，不依赖重绘。`update` 里那段 `measuredHeight>0` 判断删掉。
