## 三行规矩（开工前必读）

1. **先登记再动手**：开工前在本表加一行（一单一行），写清占用范围再改文件。
2. **范围相交不许同时开工**：与任何「在飞」行的占用范围相交 ⇒ 等它收工或协调换范围；机检跑 `python tools/check-inflight.py`，手工核对加 `--paths 路径1,路径2`。
3. **收工必须销行**：合并进 main 后删掉自己那行（或先标「已收」再删）。

## 工作树规矩（并入本表规矩，不新增流程）

- 一单一个 worktree，不共享。
- 合并前 `git fetch` 并确认基线没被别人动过同一片文件——即与本表逐行做占用核对。

## 编号归口

**批次号由蓝总管统一分配并写死在派工单里**，其他会话不再自选（两份「第四十九批」的来源）。
新单开工前先用 `git grep` 搜历史派工单与台账查号，冲突时顺延。
