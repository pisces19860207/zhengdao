## 一、总则（只有一句）

**只看「为什么写」，不看「写了多少」。**

- 不以性为目的 ⇒ **全部允许**：身体、年龄、细节都能写。
- 唯一硬红 ⇒ **未成年 ＋ 以性为目的**，三要素任一即成立：
  1. 处在性场景／性唤起语境（`MINOR-SEXUAL-SCENE`）
  2. 特写式聚焦性器官／性反应（`MINOR-GENITAL-FOCUS`）
  3. 性化凝视（`MINOR-SEXUALIZED-GAZE`）
- 这条红**没有「须核」档**：目的判定只有 `ALLOW`／`RED` 两值，不存在「商量一下」。

## 二、五维只给档

四档：**未起 → 初起 → 渐显 → 定型**（档序 0–3）。档名里没有年龄、没有数值、没有「早／晚」判词。

| 五维 | 机器落点 |
|---|---|
| 生长突增 | `PubertyDim.GROWTH_SPURT` |
| 变声 | `PubertyDim.VOICE_CHANGE` |
| 体毛 | `PubertyDim.BODY_HAIR` |
| 体型转变 | `PubertyDim.SHAPE_SHIFT` |
| 社会侧 | `PubertyDim.SOCIAL_SIDE` |

五维必须齐——缺一维的单子构造即抛（`PubertyHistory` 的 `init`）。加一维要同时改 `PubertyDim.COUNT` 与计数锁，否则门禁红。

## 三、里程碑顺序表（先后可换）

`MilestoneOrder.SEQUENCE` 是唯一表：

| 常见第几步 | 里程碑 |
|---|---|
| 1 | 生长突增 |
| 2 | 体毛腋毛 |
| 3 | 变声喉结 |
| 4 | 肌肉量与肩宽 |
| 5 | 体味痤疮 |

「**个体差异大、先后可换**」是代码里的字面量（`MilestoneOrder.SWAPPABLE`），表下必带这一行注。

- 换序**不判红**，只在注里写「本次：换过顺序」（`MilestoneOrder.isCommonOrder` / `swapped`）。
- 表与注同处一个 `object`：谁改顺序都得一起看见那句「可换」，不至于被读成体检标准。

## 四、判定（`PubertyJudge.purposeCheck`）

| 事实 | 判定 |
|---|---|
| 成年（不论三要素） | `ALLOW` |
| 未成年 ＋ 三要素全 false | `ALLOW` |
| 未成年 ＋ 三要素任一 | `RED`（每个命中要素各出一行 code） |

`purposeCheck` 的入参只有四件事：`minor` 与三个要素。**年龄数值、细节多少、档位高低都不进参数**——所以换一份更细的发育史，判定不会变（测试里有对照：同一份史换目的，档位段逐字相同）。

## 六、仍禁两条（不因「不以性为目的」而放行）

| 禁令 | code | 机器落点 |
|---|---|---|
| 医学诊断结论（性早熟／发育迟缓／骨龄／内分泌／激素水平） | `PUBERTY-DIAGNOSIS` | `PubertyGuard.diagnosisHit` |
| 由发育推性能力与品性 | `PUBERTY-INFER` | `PubertyGuard.inferenceHit` |

- 诊断结论不只是「红」，那一行**不许出线**：`PubertySheet` 会把它拦下并留一行 `PUBERTY-NOTE-BLOCKED`，其余细节照常读（不让一条坏行吃掉整张单）。
- 推断句是**三环齐才算**：发育词 × 推导词 × 结论词，缺一不红。「变声比同学早，所以常被叫去当主持」「发育得早，所以个子比同桌高」两句都是合规负例。
