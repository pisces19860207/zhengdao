## 一、要解决什么

让资料库里的**长文档有摘要** —— 用户在设置页能看到「已挂载 · 12 个文件（**含摘要**）」。

P0 只做了"清单"（有哪些文件）；P2 才让 agent 一眼看懂"每个文件讲了什么"。

## 二、为什么用太极，而不是终端 agent

| | 用谁 | 理由 |
|---|---|---|
| App 自己 | ❌ | 本地 agent 宿主，**不接 LLM API** |
| 终端 agent | ⚠️ 可行但贵 | 要花**用户自己的额度** |
| **太极（OpenCode）** | ✅ **选它** | 有**免费模型** —— 这是选它的唯一理由 |

## 三、调用通道（已查清）

来源：`oc/OcRepository.kt` 与 `oc/OcClient.kt` 的实现与注释（均为**真机实测**记录）。

| 端点 | 用途 | 响应形态 |
|---|---|---|
| `POST /api/session` | 建会话 | `{"data":{"id":"ses_…"}}` |
| `POST /api/session/{id}/prompt` | 发任务 | 请求体 `{"text":"…"}` |
| `GET /api/session/{id}/message` | 取消息（**轮询主数据源**） | `{"data":[…],"cursor":{…}}` |
| `POST /api/session/{id}/interrupt` | 中止 | 无请求体 |
| `GET /api/session` | 会话列表 | `{"data":[…]}` 按时间**倒序** |
| `DELETE /api/session/{id}` | 删会话（清理临时会话用） | —— |

**四条要点（全是项目踩过的坑）**：

1. ⚠️ **响应带 `{"data":…}` 信封** —— 不剥会**静默失败**（`OcRepository.kt:303-315` 有完整记录：
   取顶层 `id` 恒为空串 ⇒ UI 报"无法创建会话"，而 `runCatching` **捕不到异常、日志一行都没有**）
2. ⚠️ **REST 轮询才是主数据源**，SSE 只是"信号通道"（`OcRepository.kt:89-93`）
   ⇒ **不需要订阅 SSE** —— 这恰好让"后台悄悄跑一次"变得可行
3. 端口 `14000`（`OcManager.PORT`）；鉴权：`OcClient({ OcManager.servePassword })`
4. 可用性判断：`OcManager.serveRunning()`

## 四、★ 关键设计：**不碰太极的 UI 状态**

`OcRepository` 是**全局单例** —— `_state` 里只有**一个活动会话**。
走它就意味着 `switchSession` ⇒ **会把用户正在看的会话切走**。这违背"不干扰用户"。

✅ **正解**：**自己 `new` 一个 `OcClient`**。
它（`oc/OcClient.kt:41`）只是**无状态的 HTTP 封装**，用自己的 session id 直接打上面那几个端点
⇒ **完全不影响太极页**。

**代价与处理**：临时会话会出现在太极的历史列表里 ⇒ **跑完立刻 `DELETE`**。

## 五、实现步骤

```
1. if (!OcManager.serveRunning()) return null            ← 降级
2. POST /api/session                                     → sid
3. 拼提示词（读 整理/00-目录.md 的文件名列表）：
     「读 /workspace/资料库/原始/ 里的这些文件，为每个文件写 2~3 句摘要，
       用 Markdown 列表输出。⚠️ 不要写任何文件。」
4. POST /api/session/{sid}/prompt  { text: … }
5. 轮询 GET /api/session/{sid}/message（1.5s 一次，总超时 180s）
6. 取到文本 → 由 KnowledgeBase 原子写进 整理/00-目录.md 的 `## 文件摘要` 一节
7. finally { DELETE /api/session/{sid} }
8. 全程 runCatching + RunLog；失败 ⇒ 清单照旧可用
```

```
· 观察是否会弹权限请求（以及不响应时会不会卡死）
```

## 七、降级要求（实现时必须遵守）

| 要求 | 原因 |
|---|---|
| 太极没装／没跑／没模型／超时／报错 ⇒ **静默跳过**，只写 RunLog | 绝不打扰用户 |
| **绝不阻塞**设置页与终端启动（放后台 daemon 线程） | P0 已这么做 |
| **绝不因为摘要失败而让清单为空** | 清单必须先写好，摘要只是**追加**一节 |
| 摘要**只写 `整理/`**，**绝不碰 `原始/`** | 铁律 |
