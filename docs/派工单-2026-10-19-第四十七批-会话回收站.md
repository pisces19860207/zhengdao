# 第四十七批 · 会话回收站（左侧栏长按删除后能找回）

- 派单：2026-10-19 蓝总管
- 基线：取开工时最新 main（含 E-166）
- 承接：qoder
- 红线：公开仓库；真实会话/DB 不进库；单测一律合成夹具；**现有「文件回收站」行为不许变**。

## 0. 现状（用户报的问题）

用户 2026-10-19：「左侧栏的长按删除会话好像不进回收站吧？」
核对：确实**硬删**。`BaopuChatController.deleteSession()` 直接跑 `BaopuSql.deleteSessionStatements()`（5 条 DELETE：消息/part/plan/artifact 关联/session 本体），
删完不可恢复；回收站只服务**文件**（`TrashDialog` / `回收站/` 目录），会话进不去。

## 1. 目标

删除会话改为**软删**：从列表消失、进「回收站 → 会话」一节，可恢复或彻底删除；**行为对用户是「能找回」**，不是加一步劝退。

## 2. 数据层（`baopu/BaopuDb.kt`）

- 版本 **v9 → v10**：`session` 加列 `deleted_at INTEGER`（可空，NULL＝未删）；
  - `onCreate` DDL 直接带该列；新增 `applyV10Migration`（`ALTER TABLE session ADD COLUMN deleted_at INTEGER`），onUpgrade 走同一份迁移体（照 v9 的写法）。
- 新增语句（都在 `BaopuSql`，参数化）：
  - `softDeleteSession(sid, now)`：`UPDATE session SET deleted_at = ? , updated_at = ? WHERE id = ?`（只动这一行）；
  - `restoreSession(sid, now)`：`UPDATE session SET deleted_at = NULL, updated_at = ? WHERE id = ?`；
  - `listDeletedSessions()`：`SELECT id,title,updated_at,message_count FROM session WHERE deleted_at IS NOT NULL ORDER BY deleted_at DESC`；
  - `countDeletedSessions()`；
  - 彻底删除沿用 `deleteSessionStatements(sid)`（一条不改）。
- **列表过滤**：`listSessions(includeArchived)` 与 `BaopuRuntime` 里读会话的两条 SQL 都要加 `deleted_at IS NULL`；归档筛选逻辑不变。

## 3. 控制器（`ui/baopu/BaopuChatController.kt`）

- `deleteSession(sid)` 改为调 `softDeleteSession`（返回值语义不变：成功/失败）；
- 新增 `restoreSession(sid)`、`purgeSession(sid)`（调 `deleteSessionStatements`）、`deletedSessions()`；
- 删当前打开的会话时：列表刷新、当前会话置空（与现在一致，别崩）。

## 4. UI

| 位置 | 改动 |
|---|---|
| 左侧栏长按会话 → 确认框 | 文案改成「移入回收站（可恢复）」，说明「回收站里的会话可恢复或彻底删除」 |
| 回收站面板（`TrashDialog`） | 加第二节「**已删除会话（N）**」：每行标题＋最后更新＋消息数，右侧「恢复」「彻底删除」；彻底删除要**两击**（第一击只回话，第二击才真删）；空态一句人话 |
| 抽屉「回收站（N）」 | N 仍数文件（不变）；会话数在面板里单独显示（避免两个含义混在一个数字里） |
| strings | 中英成对（标题/空态/恢复/彻底删除/两击确认） |

## 5. 测试

- SQL 形状：v10 DDL 有 `deleted_at`；迁移体含 ALTER；软删/恢复/列表/计数语句完整；`listSessions` 含 `deleted_at IS NULL`；
- 源码级：`deleteSession` 不再直接调 `deleteSessionStatements`；彻底删除只从回收站两击路径进；
- 纯逻辑（可测函数）：回收站行格式化、两击状态机；
- **负例**：软删后 `listSessions` 仍能看到它 ⇒ 红；恢复后 `listDeletedSessions` 仍含它 ⇒ 红；第一击就真删 ⇒ 红。
