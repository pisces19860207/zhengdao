# 形态不推性评价（935）

- 批次：935 ｜ 分支：`feat/shape-no-judge` ｜ 工作树：`wt-935` ｜ 基线：`0a8c8e200`（934 已合）
- 落点：`app/src/main/java/com/example/zhengdao/baopu/state/bodyparts/` 新增 5 个文件，**不改**包内既有的 16 个文件。
- 由来：2026-11-26 用户「胸肌、腹肌、下体各个部位不能作为评判某个人的性张力、性吸引力、性能力的标准，这些只有个人关注点和爱好点」。

## 一、总则（只有一句）

**身体形状只说明看得见什么，不说明他是哪一种人、行不行、性不性感。**

- 934 管「职业／长相／钱权 → 品性」这条滤镜；本单管另一条更隐蔽的：**形态 → 性评价**。
- 它不评判人品，却直接评判「性感与否、行不行」；把三条推导边剪断，人物才不会被写成「健身广告 + 性能测试报告」。
- 反向同样禁：不许写「没腹肌＝失去吸引力」「瘦弱＝没张力」。只剪一头等于换一种偏见。

## 二、机器口径（怎么算命中）

- 一条断言拆成三件事：**写了什么形态**（`ShapeAspect`）／**下了什么结论**（`Judged`）／**凭什么**（`Source`）。
  判据不看语义，只对来源闭集——这是「推导边不存在」的机器表述，不是注释里的君子协定。
- 来源十格里有一格叫「形态」（`Source.MORPHOLOGY`）：它合法，但只支撑描写。它不在任何评价维的允许来源里。
- 形态档名沿用 805 的八部位与 920 的三轴，**本单不新增外观档**；868／911 只有派工单、没有代码，这里只留来源位。
- 叙述者命中 ⇒ **红**；角色命中 ⇒ **须核（＝WARN）**，理由里必须写「偏见」。
  **经验／生育力／品性** 三维不分声音，**一律红**——污名化与医学判断没有「偏见豁免」。

## 三、三条禁令与允许清单

| 判据 | 机器落点 | 允许的来源 |
|---|---|---|
| 形态 → 性张力 禁 | `ShapeRules.TENSION_SOURCES` | 观测／设定／实测（三源，闭集） |
| 形态 → 性吸引力 禁 | `ShapeRules.ATTRACTION_SOURCES` + `Preference.who` | 某个角色的口味（一源，必须带 who） |
| 形态 → 性能力 禁 | `ShapeRules.ABILITY_SOURCES` | 810 硬度/EHS ／ 868 起维持消退 ／ 911 频率 ／ 具体行为（四源，顺序固定） |

允许、且必须放行的三件事：

- **形态 → 描写**：胸肌明显／腹部圆润／骨架宽／体毛多／喉结不明显／阴囊松弛／睾丸偏小——只写看得见什么。
- **偏好 → 个人口味**：`preferenceTier`（偏好／无感／不喜），**每条带 who**；A 喜欢肌肉、B 觉得太硬、C 无所谓，三条并存合法。
- **形态 → 社会反馈**：写别人怎么看他（被多看两眼、被起哄），不写这值多少。

## 四、七类体相传闻（全禁推，唯一表在代码里）

唯一真相是 `ShapeRumorCatalog.entries`（27 条）。本文件不再抄第二份话术，只钉口径与小计：

- **A 体型与骨架**：身高／胖瘦／肩宽／骨架大 → 尺寸、能力（920 已禁身高体重，924 已禁体积↔质量互推）。
- **B 面部**：鼻子（**最常被说**）、下颌、嘴唇、下巴 → 尺寸、能力、张力。
- **C 毛发与皮肤**：体毛、胡须、发量、秃顶、青筋 → 能力。**脱发与雄激素有关，但禁推性能力**（最容易越界的一条）。
- **D 姿态与行为**：走路、坐姿、语速、声音 → 只作习惯与状态（说话方式属 930 的 `expression`）。
- **E 命理与伪分类**：血型／星座／生肖／手相／面相／八字／时辰／第几胎 → **叙述者层面直接红，不走 WARN**。
- **F 体液与生理量**：精液量／前液／汗量／勃起角度 → 不作能力、经验、健康判断；810/868 只按实测档写。
- **G 服装与配饰**：车、表、鞋、手机 → 收入或品性、能力（934 已禁「混得好≠做人好」）。

三条声音规则（同一句话三种下场）：

| 写法 | 判定 |
|---|---|
| 叙述者复述传闻 | **红** |
| 角色相信，且带「听说／都说／据说／偏见」一类标记 | **须核（WARN）**，须读成偏见、可被推翻 |
| 角色相信，但读不出是偏见 | **红**（不许把没标记的角色口当 WARN 放过去） |
| 剧情把传闻「验证」成真 | **红**（等于变相背书，最易漏的一条） |

## 五、三组最常被当符号的部位

| 部位 | 允许 | 必红 |
|---|---|---|
| 喉结 | 写形态（明显／略见／不明显）与说话起伏；喉结不明显 × 张力高 | 喉结大 ⇒ 更男人／更猛；喉结不明显 ⇒ 不够男人 |
| 阴囊松紧 | 松紧是状态（温度／提睾／紧张度／年龄）；阴囊松弛 × 吸引力强 | 「松弛＝纵欲／被用多了」⇒ **无条件红** |
| 睾丸大小 | 大小作形态记录、单侧不对称常见；睾丸偏小 × 能力正常 | 「大小 → 能不能生」⇒ **红**（医学判断） |

## 六、判据落点

| 判据 | 落点 |
|---|---|
| ① 三类夹具必须能构造 | `ShapeFixtures.absVisibleAbilityWeak` / `roundTensionHigh` / `smallAttractive`，缺一即红 |
