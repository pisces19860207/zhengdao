## 1. 设置页工具开关折叠

**现状**：`BaopuSettingsScreen.kt` 用 `ToolGroupTable` 分组（当前 **25 个工具 / 7 组**，以代码为准），每组标题下平铺所有开关，页很长；工具开关的启用逻辑在 `DEFAULT_ENABLED`/`ToolPrefs`，分组只是展示。

**改法**：
- 组头可点展开/收起；**默认折叠**；折叠态在组头下常驻一行「关闭项摘要」（列出该组被关掉的工具名；没有关闭项就写「全部开启」），**不许把关闭项藏到看不见**；「读/写工具说明」那段继续常驻，不随组收起。
- 展开/收起状态用 `rememberSaveable`，只在本次页面存活期记住；冷启动回默认折叠。
- 纯展示：**不改**任何开关的读写、默认值、`DEFAULT_ENABLED`、权限与工具行为；分组数/工具数从 `ToolGroupTable` 读，不新造第二张表。
- 文案：能复用 `common_expand_arrow` / `common_collapse_arrow` 就复用；若必须新增（如「全部开启」/「N 项关闭」），中英同步、只加本单需要的键。

**测试**：
- 纯函数：折叠态摘要的生成（全开 / 部分关 / 全关 / 空组）直测；
- 源码门禁：开关的 `prefs` 写入点零改动；折叠状态必须 `rememberSaveable`；关闭项摘要必须从同一分组表读；
- 负例：把关闭项从摘要里去掉 ⇒ 红；把组头改成不可点 ⇒ 红。

## 2. 错误留痕 1b

**现状**：`BaopuScreen.kt` 对 `libraryNote`（`:249` 附近）与 `skillNote`（`:260` 附近）各有一个 `LaunchedEffect`：非空 8 秒后 `clearLibraryNote()` / `clearSkillNote()`。但两者的赋值点混着 **进度** 与 **错误**：
- 进度：`"记下来中…"`、`"收料处理中…"`、`"导出中…"`；
- 错误：技能上限拒绝/写盘失败、资料库选项对不上/执行失败等（`BaopuChatController` 里的各个赋值点）。

**改法**：
- 给这两类便签加**级别**（Info / Error；最小实现：`data class Note(text, level)` 或控制器里多一个 `*NoteLevel` 字段），赋值点按语义标注；报告里交一张「赋值点 → 级别」清单。
- **Error 不自动消失**：不挂 8 秒 clear；给一个可点关闭（复用 `BaopuIntrospectionNote` 的 `×` 形态或现有可点便签，不新造大组件）；点掉才清。
- **Info 保持**现有 8 秒自清（进度提示不该钉住）。
- `pendingNote` 已由第一批改成持久＋可点关闭，不要重复改；三个便签的样式/位置尽量统一，别新开一行。
- 不改 SKILL 写盘/资料库动作本身，只改「提示怎么留」。

**测试**：
- 纯函数：`noteLevel` 的判定/映射（进度→Info、错误→Error）直测；
- 源码门禁：Error 路径不得挂 `delay(8_000)` 自动清；Info 路径保留；`×`/点关闭必须调既有 `clear*`；
- 负例：把错误路径改回 8 秒自清 ⇒ 红；把进度也改成常驻 ⇒ 红。
