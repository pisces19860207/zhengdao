## 分类与状态词汇（先定死）

- **补能力**：替模型/系统补能力的辅助件。会过期——模型变强或口径变了就可能不该留。必须进消融流程。
- **补信任**：制度件（账本/授权/停机/回滚）。**不许删**——它们补的是「人敢信它」，不是能力；除非用户明令废除该制度。
- **组织性**：测量与纪律的基础设施（开关件/核对包/评测床）。控维护税，不进待删；退役条件是「没人用了」，不是「能力够了」。
- 消融状态词汇：`待验`（缺 live 读数，**不许删**）→ `待删`（live 读数齐全且裁决可删）→ `已删`（单独一笔、可 revert）。补信任固定 `不许删`；组织性固定 `长留`。
- **删除纪律**：没有 live 读数的补能力件不许删；删除必须单独一笔提交、可 `git revert`；状态先于动作落表。
