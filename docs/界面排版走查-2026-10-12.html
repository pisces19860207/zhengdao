5.4 「慢」与「突然出信息」：成因与无感化方案（2026-10-12 用户反馈）

成因（② 代码原文）：① 11 项体检串行跑在一条 IO 线程上（EnvHealth.kt:161/169-170 的 items.map），总耗时 = 各项之和；② 慢项：diskCheck 走 Java 递归遍历几千个文件（StorageAudit.kt:132/338 → CacheCleaner.kt:537-545）、networkCheck 有 1.2 秒 TCP 超时（EnvHealth.kt:365-370）、resourceCheck 读 /proc；③ 无缓存，每次展开（HomeScreen.kt:181-187）与展开态每次 ON_RESUME（:262-264）都从零全跑；④ 全有或全无渲染——回填前显示“环境体检中…”（:391-396），然后 11 行同时出现，即“突然出信息”。

#措施做法解决什么
1缓存优先（stale-while-revalidate）上次结果留内存（可选落盘）；展开即渲染旧值，后台刷新，只更新变化的行慢、空白、吓人
2并行采集coroutineScope { ITEMS.map { async(Dispatchers.IO) { … } } }，墙钟耗时 = 最慢一项慢
3流式上屏每项完成即发射，快项先出；行级淡入，尊重系统减弱动效突然出信息
4分级刷新快项（文件 stat，毫秒级）每次展开都跑；慢项 30–60 秒内不重复慢、重复等待
5慢项旁路TCP 超时 1.2s → 600ms，只配给“慢车道”慢

Rust 帮不上忙，理由（②+③）：这套检查是 I/O 与网络 bound（文件元数据 syscall、/proc 读、一次 TCP 连接），Rust 让 I/O 和网络延迟变小不了；项目实测 native vs Java 的 SHA256 收益 <2%（② EnvHealth.kt:436-438 引 ERRATA），那是 CPU 密集型都比这收益大。唯一可能加分的是目录遍历——dirSizeMb 已走 native（② SystemInfoProvider.kt:266-272，边界只跨一次），但磁盘体检那条路（StorageAudit → fileLengths）没走；把审计切到 native 遍历可能砍掉最大一块，但这是“改用已有 native 函数”而非“用 Rust 重写体检”，且要先测量确认遍历真是瓶颈（③）。对照项目既定裁定：单函数跨 JNI 搬大块数据永远亏，“用 Rust 重写 EnvHealth”正是最亏的形态。

结论：无感化 = 缓存 + 并行 + 流式 + 分级刷新（纯 Kotlin，确定性收益，估 1–2 天）；Rust 只在目录遍历一处待测量后可能加分。

@Composable
internal fun SettingRow(
    label: String,
    value: String,                     // 约定：≤6 字短状态
    valueColor: Color = Color.Unspecified,
    onClick: () -> Unit,
) {
    Row(
        modifier = Modifier
            .fillMaxWidth()
            .clickable(onClick = onClick)
            .padding(horizontal = 16.dp, vertical = 14.dp),  // 行高 ≥48dp
        verticalAlignment = Alignment.CenterVertically,
    ) {
        Text(                      // 设置名 = 主角
            text = label,
            style = MaterialTheme.typography.bodyLarge,      // 16sp
            color = MaterialTheme.colorScheme.onSurface,     // 主文字黑
            maxLines = 1,
            overflow = TextOverflow.Ellipsis,
        )
        Spacer(Modifier.width(12.dp).weight(1f))
        Text(                      // 状态 = 辅助，退后
            text = value,
            style = MaterialTheme.typography.bodySmall,      // 13sp
            color = valueColor.takeIf { it != Color.Unspecified }
                ?: MaterialTheme.colorScheme.onSurfaceVariant,
            maxLines = 1,
            overflow = TextOverflow.Ellipsis,
        )
        Spacer(Modifier.width(6.dp))
        BackChevron(tint = MaterialTheme.colorScheme.onSurfaceVariant)
    }
}
