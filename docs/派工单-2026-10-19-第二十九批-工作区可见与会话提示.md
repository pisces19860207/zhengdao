## 0. 一句话

工作区现在藏在设置页里 ⇒ 抽屉看不出「抱朴此刻在哪个文件夹干活」。本批把抽屉改成**按工作区归组的会话树**（DSH／workbuddy 那样），并把「另一个会话在跑」从一句拒绝改成**先问人**。

## 2. 规格

### A 段（必做）· 抽屉顶部 = 工作区树

```
＋ 新会话
工作区                      ← 小节标题（右侧留空位，将来放搜索/加文件夹）
📁 AndroidStudioProjects
      玄览白屏 WebView 修复派…        20 小时
      继续之前会话的超限任务           21 小时
📁 男性                    ← 当前工作区，整行高亮
      你好呀                          刚刚      ← 当前会话，行高亮
      查看 ai-xan.xyz 网页内容         20 天
📁 默认工作区 · 历史未记录
```

硬要求：

1. **文件夹行**：`📁 ＋ 末级文件夹名`，名字取 `File(Workspace.hostDir(ctx).absolutePath).name`。
   **不许自己截串**、**不许显示完整路径**（`/storage/.../Download/男性` ⇒ 只显示 `男性`）。
   - 私有模式 ⇒ `🔒 App 私有`；未授存储权限 ⇒ `⚠️ 未授权`（点它去设置页）
2. **会话行**：标题（超长省略，只一行）＋ 右侧**相对时间**（`刚刚` / `N 分钟` / `N 小时` / `N 天`，取 `updated_at`）。
   **不许**把 `preview` 摘要塞进来 —— 只有标题 ＋ 时间。
3. **当前项高亮**：当前工作区整行高亮；当前会话行也高亮（两者别用同一个视觉强度）。
4. **分组口径**：
   - 按 `session.workspace` 分组；
   - **NULL 的老会话**归「`📁 默认工作区 · 历史未记录`」组，**排在最后**（与第二十五批追加一同口径，那批只在会话库里做过，这里复用同一规则）；
   - 当前工作区**一定显示**（哪怕它下面没会话）；其余只显示**有会话的**；既没会话又不是当前的，不占地方。
5. **点一下**：
   - 点文件夹行 ⇒ 一行小字提示完整路径（**看完自动消失，不许常驻**）＋ 落点是设置页「工作区」卡；
   - 点会话行 ⇒ 切到那个会话（撞上单活跃门就按 B 段弹确认）。
6. **交互克制**：不许做展开/收起动画特效；小节标题右侧留位置但**本批不做搜索**。
7. **图标只用文字符号**（`📁` / `🔒` / `⚠️`）：**不许引图标库、不许新自绘 glyph**。

### A2 段（必做）· 两行文案改实

- 「新会话」desc ⇒ 「在当前工作区开一个新会话，记忆不动」
- 「历史会话」desc ⇒ 「全部会话，平铺看」（那页**保留**作平铺列表，抽屉成为主入口）

### B 段（必做）· 单活跃会话要能一键过去

另一个会话在跑时，切过来发送**不许只回一句「已有另一个会话在跑」**：

- 弹确认：「`<会话标题>` 还在跑。要**停掉它**并在这个会话继续吗？」按钮「停掉并切过来」／「取消」；
- 选「停掉并切过来」⇒ 先 `engine.stop()` 那一个（**走既有停止路径，不新造状态**），再放门；
- 🛑 **不许自动停**：用户没点就停别人的会话是事故。

### C 段（纯文档，一句话即可）

报告里写清并**原样引用**这段口径（`docs/KERNEL.md` 由蓝总管补，**你不要动它**）：

> **能存多个会话；同时只允许一个在跑。** 理由三条：① 两个 run 会往**同一个工作区**写文件、互相覆盖；
> ② 确认卡／问人卡只有一套 UI，两个 run 抢同一张卡会串台；③ token 与电量翻倍，手机上第一个卡死的是内存。
> 真要并行，前置三条：每会话独立工作区（或只读）、工具调用全局串行化、每会话独立 token 预算。**现在不做。**

### ⛔ 明确不在本批（别顺手做）

- **预览两个入口**（「预览这条回复」／「清空预览缓存」）：等你自己的刀 4-B（`BaopuPreview.kt` ＋ `previewLastReply`／`clearPreviewCache`）落地后才接线。
  **本批不许碰 `ui/baopu/BaopuPreview.kt`**（你自己正在改），也不许提前在抽屉里加这两个 item。
- 搜索／加文件夹／并行会话。
