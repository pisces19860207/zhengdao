## 2. 规格

### 2.1 A 段 · 抽屉顶部显示工作区（必做）

- 抬头下加一行：**「工作区：`…/Download/男性`」**（长路径中段省略，保留前 12 后 12 字）；
  - `Workspace.isPrivate(ctx)` ⇒ 显示「工作区：App 私有（不进文件管理器）」
  - custom/devault 都显示绝对路径；未授存储权限 ⇒ 显示「工作区：`（未授权）`」，点它跳设置页
- 点这一行 ⇒ 直接打开设置页的「工作区」卡（不新做页面）；
- **两行文案改实**：
  - 「新会话」desc 改成「在当前工作区开一个新会话，记忆不动」
  - 「历史会话」desc 改成「以前聊过的（按工作区分组），点一条接着聊」

### 2.2 B 段 · 单活跃会话的提示要能一键过去（必做）

现状：另一个会话在跑时，切过去发送只回一句「已有另一个会话在跑」。改成：

- 弹确认卡／对话框：「`<会话标题>` 还在跑。要**停掉它**并在这个会话继续吗？」按钮「停掉并切过来」／「取消」；
- 选「停掉并切过来」⇒ 先 `engine.stop()` 那一个（走既有停止路径，**不新造状态**），再放门；
- **不许**自动停（用户没点就停别人的会话是事故）。

### 2.3 C 段 · 多会话并行：本批**不做**，只写进文档（必做，纯文档）

在 `docs/KERNEL.md`（第二十六批产出）或本节引用处写清：

> **能存多个会话；同时只允许一个在跑。** 理由是三条：① 两个 run 会往**同一个工作区**写文件、互相覆盖；
> ② 确认卡/问人卡只有一套 UI，两个 run 抢同一个卡会串台；③ token 与电量翻倍，手机上第一个卡死的是内存。
> 真要并行，前置三条：每会话独立工作区（或只读）、工具调用全局串行化、每会话独立 token 预算。**现在不做。**
