# 模型登记表（`docs/models-registry.md`）

> **本文件是模型权重的唯一登记表**（第六百三十四批，2026-11-14），机器判据是
> `tools/check-model-registry.py`，已挂进 CI（`ci.yml` supply-chain job，会红、会拦）。
> 一行一个模型，**十列缺一不可**；空格子那一行不算登记。
>
> 为什么是 `.md` 而不是 `.json`：登记要给人看（用户不懂代码，验收靠读账），
> 而机器判据只需要一张形状固定的表。同一张表既能被人扫，也能被脚本解析，
> 不维护第二份 JSON 副本（第二份真相必然漂移，423／424 已经吃过这个亏）。

## 一、它补的是哪个洞

| 工具 | 判什么 | 不判什么 |
| --- | --- | --- |
| `tools/check-license-policy.py`（423） | **代码依赖**（Maven POM / Rust）的许可是否准用 | 模型权重、字体这类「没有 POM 的资产」 |
| `tools/check-license-policy.py --assets`（433／440） | `app/src/main/assets/` 下**每个文件**是许可允许的（或第一方名册） | 这个资产**能不能商用**、**能不能再分发**、身份有没有钉住（sha256／体积／来源） |
| `tools/gen-notices.py`（424） | 第三方声明清单与依赖一致 | 同上 |
| **本表 ＋ `check-model-registry.py`（634）** | 模型权重的**十件事**：来源、许可、可商用、可再分发、体积、sha256、云/端、状态 | 依赖许可（归 423）、资产是否登记（归 440） |

三本账**各判各的、都要过**：一个随包的模型权重，既要出现在 `licenses/ASSETS.md`
（440 判「许可在允许表内」），也要出现在本表（634 判「可商用／可再分发／身份钉住」）。
只登一本 ⇒ 另一本先红，这是设计，不是冗余。

## 二、四条口径（本单写死，改口径 ＝ 改脚本 ＋ 过评审）

1. **默认不内置权重。** 能用用户自己的 API key 解决，就不往 APK 里塞模型。
   一个权重进包，代价是体积、冷启、以及许可证义务，三样都要长期还。
2. **必须内置时（如离线兜底），只能选 Apache-2.0 / MIT / BSD 类**
   （`BSD-2-Clause`、`BSD-3-Clause`）。**CC BY-NC 一律不许**——它的 NC 就是
   「不可商用」，与本项目（商用分发）直接冲突，不是「注意一下」的量级。
3. **按需下载的模型**：登记 `sha256` ＋ 来源 URL ＋ 许可，**下载后必须校验 sha256**，
   校验不过就用不了（不许「先跑起来再说」）；模型文件放在 App 私有目录，
   **用户可删**，删掉后该项回到「未安装」（不假装可用、不静默回退）。
4. **许可不明（查不到 LICENSE）⇒ 不许进。** 与依赖闸同口径：
   「查不到」不等于「没问题」，未登记不算通过。

## 三、十列怎么填

| 列 | 端侧（`端`）填什么 | 云端（`云`）填什么 |
| --- | --- | --- |
| `id` | **相对 `app/src/main/assets/` 的精确文件路径**（正斜杠，可加反引号；不许目录、通配、`..`）。例：`models/asr-tiny.tflite`。与 440 的「资产名」同一口径，不另立键。 | 模型 id，与 `app/src/main/assets/models/model-labels.json` 的 `modelId` 同口径。例：`deepseek-flash` |
| `名称` | 界面上给人看的名字（与 `model-labels.json` 的 `displayName` 同风格：系列＋版本＋档位，不带公司名） | 同左 |
| `来源URL` | 下载地址（必须是 `http(s)://`）。**不许留空、不许写「官方」这种话** | 官方定价／许可／模型页 URL 之一 |
| `license` | SPDX 名，如 `Apache-2.0`／`MIT`／`BSD-3-Clause`。端侧只允许这四个家族（见口径 2） | 服务条款或权重的 SPDX 名。不许留空、不许写「不明」 |
| `可商用?` | `是`。填 `否` ⇒ **红**（口径里没有「先用着」这一档） | 同左 |
| `可再分发?` | `是`。随包或提供下载都算再分发，填 `否` ⇒ **红** | 填 `—`（云端不复制模型文件，不存在再分发动作） |
| `体积` | 如 `173 MiB`（单位只认 `B`／`KiB`／`MiB`／`GiB`）。与磁盘实际大小差 >2% ⇒ **黄**（提示，不红） | `—` |
| `sha256` | **64 位小写十六进制**。文件在盘上时必须与真文件一致，不一致 ⇒ **红** | `—` |
| `云/端` | `端` | `云` |
| `状态` | `内置`（随包）／`按需下载`（用户触发下载）／`候选`（还没进包也没下载） | `在用`／`停用`／`候选` |

`—` 是**唯一**的「不适用」记号（写成半角 `-` 也认）。**它在 `license` 列不算填写**：
许可填 `—` ＝ 许可不明 ⇒ 红。

## 五、判据（红／黄／绿）

**红（退出码 1，CI 拦）**

| 触发 | 消息关键词 |
| --- | --- |
| 磁盘上有模型权重文件（`app/src/main/assets/**` 下命中模型扩展名），表里没有这一行 | 未登记 |
| 任何一行 `license` 空、`—`、或写「未核／不明／unknown／tbd／待定」 | 许可不明 |
| 任何一行 `可商用?` = `否`（或不是 `是`） | 不可商用 |
| 端侧行 `可再分发?` ≠ `是` | 不可再分发 |
| 端侧行 `license` 不在 `Apache-2.0`／`MIT`／`BSD-2-Clause`／`BSD-3-Clause` 内（含 CC BY-NC、GPL、OFL 等） | 不在允许表／NC |
| 端侧行 `sha256` 不是 64 位十六进制 | sha256 格式 |
| 端侧行 `sha256` 与磁盘真文件不一致 | sha256 不符 |
| 端侧行 `状态=候选`，但该文件确实在 `assets/` 里随包 | 状态撒谎 |
| 十格有空、格数不是 10、`云/端`／`状态` 取值不在闭集内、`id` 路径非法、同一 `id` 两行 | 格式 |

**黄（提示，退出码仍是 0）**

- `状态=内置` 的行，文件在盘上找不到（登记表过期；删了文件就删行）；
- 端侧行 `体积` 与真实大小差 > 2%（四舍五入误差除外）；
- 云端行把 `体积`／`sha256` 填成了非 `—`（云端没有包体，这两列无从谈起）。

**绿（退出码 0）**：以上红一条都没有。零行表 ＋ 零个权重文件也是绿——**这是当前的真状态**。

**环境错误（退出码 2，不算通过）**：登记表被删、十列表头找不到。
删表不能变绿，与 440 的「名册被删 ⇒ exit 2」同一防线。

## 六、模型扩展名闭集（脚本判「这是不是权重」的唯一依据）

```
.gguf .onnx .tflite .litertlm .task .ort .safetensors .pt .pth .bin
.mlmodel .model .param .npy .npz
```

只扫 `app/src/main/assets/`（与 440 资产门禁同范围），不扫 `androidTest` 的
assets、不扫构建产物、不扫 APK 内容。扩展名不在表里 ⇒ 不算权重、不要求登记；
**扩这个表 ＝ 改脚本**（改脚本会进评审，不许在单子里口头加）。

`.bin` 在闭集里是**故意的**：633 的本地语音模型占位文件名就叫 `model.bin`
（`AndroidSpeechEngine.LOCAL_MODEL_FILE`），它落在 App 私有目录、**不在 assets**，
所以不会命中本闸。将来谁把 `.bin` 放进 assets，会先红一次——红了的正确解法是把
文件挪出去或改扩展名，**不要为它编一行登记**。

## 七、按需下载的落地要求（口径 3 的展开）

1. 下载前：从本表取 `来源URL` ＋ `sha256`（**唯一来源是本表**，不许在代码里再写一份常量）。
2. 下载后：算 sha256 与表中值比对，不一致 ⇒ 删掉半成品、报错、`installed()` 仍返回 `false`。
3. 存放：App 私有目录（与 633 的 `filesDir/voice/model.bin` 同款），**不进工作区、不进日志**。
4. 删除：设置页给「删除模型」入口，删掉后该项回「未安装」，界面灰掉而不是假装可用。
5. 校验失败／未下载 ⇒ 绝不静默回退到云端模型（633 的 `VoiceGate` 同款口径）。

## 八、怎么跑

```
python3 tools/check-model-registry.py            # 门禁（CI 用这个）：红 ⇒ 退出码 1
python3 tools/check-model-registry.py --selftest # 自检：临时目录里造夹具，三例判据＋九条守卫＋防假绿
python3 tools/check-model-registry.py --root .   # 指定仓库根（本机排查用）
```

自检不写仓库内任何文件（夹具全在临时目录），不联网。
