## 0. 为什么有这一单

第四十八批只交付了**抱朴** P0-1～P0-4；**P0-5 不是抱朴的事，属终端/环境（rootfs）**，之前只挂在 §B 76 的备注里、没单独派单（这是账务分类的错，不是抱朴范围的漏做）。现状在最新 `main` 上仍在：

- `RootfsInstaller.swapLocked`（`rootfs/RootfsInstaller.kt:527-572`）：旧树 `renameTo(backup)` → 新树就位 → `backup.deleteRecursively()`；**全程不看会话**，只持 `withInstallLock`。
- 设置页四条路径都不先处理活会话：
  - `ui/SettingsEnvActivity.kt:612` 修复环境；
  - `ui/SettingsEnvActivity.kt:730` 增量更新 `RootfsDelta.apply`；
  - `ui/SettingsEnvActivity.kt:791` 全量更新；
  - `ui/SettingsStorageActivity.kt:744` 回退环境版本。
- `TerminalActivity.kt:1900` 的 `SessionManager.kill` 是**安装完成后**才调，不是替换前守卫。

后果：proot/agent/tmux 还跑着时，旧 rootfs 被改名再递归删除 ⇒ 运行中的会话后续 `open`/`exec` 可能 ENOENT，当场碎在半路。审计标 ②（真机破坏效果未实测），但**代码里确实没有守卫**。

## 1. v1 行为（只做「拒装」，不自动杀会话）

- 新增一个**纯函数**门禁（放 `ui/InstallFlow.kt` 或新建 `ui/EnvInstallGate.kt`）：
  ```kotlin
  internal fun liveSessionBlocksEnvInstall(alive: Boolean): String?
  ```
  `alive == true` 返回固定文案；`false` 返回 null。文案必须包含「先结束当前终端会话」与「本次没有改动任何文件」。
- 四条设置页路径在**任何下载/解包/替换/回退之前**先查：
  ```kotlin
  if (SessionManager.isAlive()) { 显示 liveSessionBlocksEnvInstall(true)!!; RunLog.log(...); return }
  ```
  - 用 `SessionManager.isAlive()`（`terminal/SessionManager.kt:126`），不要用 `hasSession()`（会话对象在但已死也会 true，会误拒）。
  - 失败走 Snackbar/Toast/RunLog 即可；**不要**调 `InstallFlow.fail()`/报「环境安装失败」——这是前置条件不满足，不是安装失败，别污染问题卡。
  - 用户结束会话后重试，流程照常。
- **v1 不自动 kill**：静默杀会话会打断用户正在跑的 agent；要「确认后结束会话并继续」是 v2，不在本单。
- **调用点盘点**：除上述四条，再全文检查 `RootfsInstaller.install` / `RootfsDelta.apply` 的其他调用方（终端页首装等），在报告里逐个说明「为什么不需要/需要守卫」；终端页自己的流程不改。
- 不改 `RootfsInstaller` / `RootfsDelta` 内部，保持 `rootfs` 不反向依赖 `terminal`（守卫在 `ui` 层）。

## 2. 测试（先红）

- 纯函数：`alive=true` ⇒ 非空且含「结束当前终端会话」「没有改动任何文件」；`alive=false` ⇒ null。
- 行为（JVM，假 installer）：门禁为真时，安装 lambda **一次都不被调用**，临时 rootfs 字节/树不变；门禁为假时照常调用。
- 源码门禁：四条设置路径里，`SessionManager.isAlive()` 检查必须出现在 `RootfsInstaller.install` / `RootfsDelta.apply` 之前；漏一条即红。
- 负例：删掉任意一条的守卫 ⇒ 门禁红；把 `isAlive` 换成 `hasSession` ⇒ 纯函数/文案用例按预期红（或补一条反例）；逐字节复原并附 `git status`。
- 全量单测 0 失败/0 错误，跳过数不恶化；lint 预算不升。
- 真机可选：开一个终端会话 → 设置页修复/更新 ⇒ 应被拒且零文件改动；结束会话后重试 ⇒ 正常。拿不到设备就在报告里写「真机未验」。
