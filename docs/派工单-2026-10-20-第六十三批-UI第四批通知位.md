## 0. 背景与边界

UI/UX 评审 5 号：抱朴页消息流之上可垂直堆叠至多 8 条横条（顶条、防丢横幅、SessionBar、pendingNote、skillNote、libraryNote、CopyBox、底部卡区）。本单做**通知位合并**，把「条」归位成「一条通知位 + 一个抽屉」；**不是删功能**。

三条保命线：
1. **CopyBox 位置/形态不动**（2026-10-18 用户已定稿「形态很好」）；
2. **底部卡区不动**（确认/问人/记忆/技能提案是 harness 安全闸，10-19 用户已点名 ask 卡位置）；
3. 续跑/导出这类**行动入口必须直接长在通知条上**，不许藏进「+N」。

## 1. 要合并的条目（功能一个不能少）

| 旧位（触发条件） | 功能 | 新家 |
|---|---|---|
| 防丢横幅（原件超期） | 超期提醒 + 一键导出 | 通知位（行动级，条上带「导出」） |
| SessionBar（中断/notice） | 中断提示 + 续跑 | 通知位（行动级，条上带「续跑」）；**空态整条不渲染**（第一批已做，别回退） |
| pendingNote | 记忆写入失败原因 | 通知位（错误级，常驻可关；61 批已接 `BaopuIntrospectionNote`） |
| skillNote / libraryNote | 技能/资料库错误或进度 | 通知位（按 61 批分好的 Info/Error 级别；Error 常驻、Info 可自清） |
| 顶条 / CopyBox / 底部卡区 | — | **不动** |

## 2. 行为规格

- 通知位**同一时刻只显示最高优先级一条**：**错误 > 行动 > 提示**。
- 其余条目折成「+N」入口；点开 `bottomSheet` 看全量，每条都可操作（行动类带按钮，错误类可关）。
- 通知位为空时**整条不渲染**（不留 16dp 空条）。
- 行动类（导出/续跑）未处理前常驻；错误类按 61 批级别常驻；提示类可自动退。
- 顶条、CopyBox、底部卡区的位置/顺序/形态保持不变；本单只改它们**之间**那一段的条件条。
- 不新增第二套通知样式；尽量复用现有 Surface/颜色/字号/圆角令牌。

## 3. 测试（先红）

- 纯函数：通知优先级排序（错误 > 行动 > 提示）、「+N」计数、同优先级去重/稳定顺序，直接 JVM 测。
- 源码门禁：
  - 消息流上方不得再出现「防丢横幅 / SessionBar / 三个便签」各自独立的常驻渲染块（必须统一走通知位）；
  - CopyBox / 底部卡区 / 顶条的渲染点零改动（可用切片断言）；
  - 通知位空态必须在 `if` 内（不得回退成常驻空条）。
- 负例：把优先级改反 ⇒ 红；把导出/续跑藏进 bottomSheet ⇒ 红；把 CopyBox 收进通知位 ⇒ 红。
- 全量单测 0 失败/0 错误，跳过数不恶化；lint 预算不升。
- 真机可选：最坏情况（超期+中断+错误便签）首屏只剩顶条 + 通知位 + CopyBox；没验写「真机未验」。
