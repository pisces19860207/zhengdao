## 0. 一句话

多张图片现在是**一张一行竖着堆**（`BaopuMessageList.kt:468` 用的是 `Column` ＋ `spacedBy`），
看起来像三块错位的补丁。改成**并排**：放得下就一行，放不下换行，等宽等高、间距一致。

## 1. 现状（2026-10-18 真机 ＋ 源码）

| 事实 | 证据 |
| --- | --- |
| 气泡里图片区是**竖排** | `ui/baopu/BaopuMessageList.kt`：`if (imageParts.isNotEmpty()) { Column(...) { imageParts.forEachIndexed { … } } }` |
| 单图尺寸 96dp | 同文件 `IMAGE_THUMB_DP = 96.dp`（第二十四批 B 段定的） |
| 输入框附件是**纯文字行** | composer 里每张一行「附件: 附件/xxx.png (251183 B) 移除」，三张就是三行字，跟「图片」这件事完全不搭 |

## 2. 规格

### A 段（必做）· 气泡里的多图并排

1. **排列**：放得下就**一行并排**；一行放不下就**换行**（每行同样数量，别让最后一行孤零零一张居中）。
   气泡最大宽度内一排放几张：**按 96dp ＋ 4dp 间距算**，至少保证**手机上 3 张能挤一行**（不够就把单图缩到 84dp，别超）。
2. **等宽等高**：全部**正方形**（`aspectRatio(1f)`）＋ `ContentScale.Crop`，同一行**同尺寸**，**不许**按图片原始比例变形。
3. **圆角与间距**：统一圆角（沿用现有气泡圆角口径）、间距 **4dp**；
   图片区与文字 hint 之间 **6dp**。
4. **单图不变**：只有一张时仍是 96dp（别为了并排把单图缩成小方块）。
5. **交互逐张独立**：点第 N 张 ⇒ 全屏打开**第 N 张**（不许都打开第一张）；长按复制**该张**的相对路径。
6. **缺图**：哪张找不到就**在该位置**显示一行「图片找不到了」占位（占一个 96dp 方块的宽），**不许**整区塌成一个空白方块。
7. **不许**：不引图片库（`Glide`/`Coil` 之类）、不新自绘 glyph、不做动画特效。

### B 段（必做）· 输入框附件条也并排

现在是三行文字。改成**横排缩略图 chip**：

```
[ 图 ] [ 图 ] [ 图 ]  ← 每张 56dp 方块缩略图（圆角 8dp）
   ×      ×      ×     ← 右上角小 × 移除
```

- 一行放不下 ⇒ **横向滚动**（不许换行把输入区顶高）；
- 非图片附件（txt/pdf）仍用**一条文字 chip**（`文件名 ＋ 移除`），与图片 chip 视觉区分（一个有底色一个有缩略图即可）；
- 数量上限沿用现口径（`MAX_ATTACH = 9`），满 9 张时再加要提示（沿用现有文案）；
- **落盘路径与字节数**不用一直显示（点一下 chip 才看得到路径，或长按复制）—— 但**不许**把「相对路径」这个语义改掉（B1 判据仍然只收相对路径）。

| 编号 | 判据 |
