## 2. 规格

### 2.1 内存预览槽（本批主件）

新建包 `app/src/main/java/com/example/zhengdao/preview/`，**只允许**两块：

1. **`PreviewSlots`（纯逻辑，能进 JVM 测试）**
   - `put(html: String, assets: Map<String, ByteArray> = emptyMap()): PutResult`
   - 槽上限 **8**；满了按 **LRU** 淘汰最久未访问的一个（淘汰后该 url 变 404）
   - 返回 `http://127.0.0.1:<port>/p/<uuid>`；uuid 由 `UUID.randomUUID()` 生成，**不可猜**
   - `get(id)` / `touch(id)` / `remove(id)` / `clear()`；`Stats(capacity, used, evicted)`
   - **线程安全**（`synchronized` 或不可变快照皆可，写清理由）
2. **`PreviewServer`（最小 HTTP，`ServerSocket` 手写即可，不引依赖）**
   - 只 `bind` **127.0.0.1**，端口从固定候选列表（例：`7[0-9]00` 段）依次试，**占用就顺延**；全失败 ⇒ `put` 返回失败并带上原因（**不许静默不启动**）
   - **只认 `/p/<uuid>` 这一种路径**：`uuid` 只是**内存 map 的 key**，**永不按请求路径读盘**（这条是硬红线：路径不得参与 `File` 构造）
   - 只允许 `GET`/`HEAD`（其余 `405`）；未知 uuid ⇒ `404`（响应体固定一行，不区分「不存在」与「已淘汰」）
   - 子资源：`/p/<uuid>/<name>` 从 `assets` 里取，取不到 `404`；**`name` 里出现 `..`、`/`、`\`** ⇒ `404`（不做路径归一化，直接拒）
   - 响应头：`Content-Type` 按扩展名（`html`/`css`/`js`/`png`/`svg`/`json`，其余 `application/octet-stream`）、`Cache-Control: no-store`、`X-Content-Type-Options: nosniff`
   - 线程名登记 `zd-preview-*`（**必须在 `util/BareThreadGuardTest.kt` 里加登记**，否则门禁红）
   - 子进程/端口：**不要**起子进程；只用 `ServerSocket`

### 2.2 `screenshot(fullPage)` 真做

- `fullPage` ∈ {`"1"`,`"true"`} ⇒ 截**整页**：优先 `WebView.capturePicture()` 路线；若拿不到（内容高度 0 或超过上限），**降级为可视区并在回执里明说**「页面过高/未取到布局，已退化为可视区」——**不许**假装截了全页。
- 上限：内容高度 **≤ 20000 px** 且宽 **≤ 4096 px**，超了就按比例缩到上限内并在回执里报实际尺寸与缩放比。

### 2.3 局部截图（新能力）

- 新增参数 `selector`（与 2.4 同一套校验），有它就**只截那个元素**：
  `document.querySelector(sel).getBoundingClientRect()` 拿矩形（含滚动补偿）⇒ 整页位图裁剪；
- 元素不存在 ⇒ 回执 `NOT_FOUND`（**不许**回一张整页图充数）；元素为 0×0 ⇒ 回执明说「元素没有尺寸」。

### 2.4 `snapshot(selector)` 不许再静默

- 真做：`selector` 给定 ⇒ 只返回**该元素子树**的可交互元素与可见文字（用 `querySelectorAll` 在子树里取）；
- 元素不存在 ⇒ 回执**报错**「找不到元素：<selector>」；
- 若你判断「真做」风险大，退路是**明确拒绝**：回执说「selector 暂不支持」——**但绝不能**继续「忽略 selector 回整页」这种假过滤。
- 三条（`snapshot`/`click`/`type`）的 selector 校验必须继续走 `BridgePolicy.checkSelector`（**不许**绕开）。
