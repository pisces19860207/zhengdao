## 二、已交付（可讲的部分）

- **抱朴 harness**：工具循环、风险分档、副作用账本与回滚、技能草稿/转正、记忆提炼、会话压缩与续跑；
- **玄览（浏览器）**：多标签、快照与操作、人教一遍就能记住流程；
- **决策中心**：十类副作用统一记账，可看、可撤、可抽检；
- **技能契约**：每条技能写清"什么时候用/算不算成/不许碰什么"，缺契约不许自动选中；
- **独立复核（勘验）**：只读查账，输出三行结论，明细不进模型上下文；
- **调解**：在刚性制度下管理人机协作体验（细节私有）；
- **终端**：已拆为独立 App（PTY＋rootfs＋proot），主仓不再维护。

## 三、明确不做（有理由，不是遗漏）

| 不做 | 理由 |
|---|---|
| 在 App 内跑 shell / 起子进程 | 那是终端 App 的事；主仓只做 harness 与浏览器 |
| 物流场景深挖（价格核算、多渠道比价） | 定位是"查询助手"，不是物流系统 |
| 把模型权重当技能 | 技能是文件＋索引＋审计，不是权重 |
| 无人值守全自动 | 不承诺；高风险动作永远要人点头 |
| 跨站点自动泛化 | 不承诺；同一意图至少两个站点各验一次才算学会 |

## 四、为什么不全公开

写清"怎么判、怎么放权、怎么学完才算数"的文档＝**操盘手册**：抄实现要读代码，抄文档一天就能贴脸。
所以：**公开讲定位与用法，私有存判据与策略**；代码仍公开，靠实现反推的成本高一截。
