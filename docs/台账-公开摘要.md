## 二、已交付（可讲的部分）

- **抱朴 harness**：工具循环、风险分档、副作用账本与回滚、技能草稿/转正、记忆提炼、会话压缩与续跑；
  工具面现为 **119 条注册 / 19 组**；
- **玄览（浏览器）**：多标签、快照与操作、人教一遍就能记住流程；会话页可记网址标题、按设备尺寸导出（未加载完拒绝导出）；
- **决策中心**：副作用统一记账，可看、可撤、可抽检；另有"项目账本"与"待办中心"两块；
- **本机 MCP 服务端**：默认只绑 `127.0.0.1:8765`，令牌/白名单/租约/审计/停机五道闸；
- **文件能力**：工作区读写之外支持 `content://` 读取（认得出、说得清、限读、不落产物）；
- **装配失败不静默降级**：错误页三钮＋诊断落盘＋安全模式；工具失败线索写进运行账；
- **学习板块**：边看边纠（插话暂停、从第 N 步重跑、改脚本确认留痕）；模型可提交学习草案与轨迹摘要；
- **技能契约**：每条技能写清"什么时候用/算不算成/不许碰什么"，缺契约不许自动选中；另记"现实指纹"，改版换表头后先降级为「需确认」，连续 3 次对不上才停用；
- **独立复核（勘验/巡按）**：只读查账，输出三行结论，明细不进模型上下文；
- **调解**：在刚性制度下管理人机协作体验（细节私有）；
- **终端**：已拆为独立 App（另仓 `zhengdao-term`），主仓不再维护。

## 三、明确不做（有理由，不是遗漏）

| 不做 | 理由 |
|---|---|
| 在 App 内跑 shell / 起子进程 | 那是终端 App 的事；主仓只做 harness 与浏览器 |
| 物流场景深挖（价格核算、多渠道比价） | 定位是"查询助手"，不是物流系统 |
| 把模型权重当技能 | 技能是文件＋索引＋审计，不是权重 |
| 无人值守全自动 | 不承诺；高风险动作永远要人点头 |
| 跨站点自动泛化 | 不承诺；同一意图至少两个站点各验一次才算学会 |

## 四、为什么不全公开

写清"怎么判、怎么放权、怎么学完才算数"的文档＝**操盘手册**：抄实现要读代码，抄文档一天就能贴脸。
所以：**公开讲定位与用法，私有存判据与策略**；代码仍公开，靠实现反推的成本高一截。
