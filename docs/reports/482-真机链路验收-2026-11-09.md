## 3. 模型层为什么是脚本（如实交代）

- 真机上的正式包是 release 签名，debug 包**签不过**；为了让用户数据不动，只能走 suffixed 新包 ⇒ **新数据目录里没有 API key**；
- 本机没有可用 key 的来源（我没去读用户的凭据文件，也不该读）；
- 模拟器因磁盘不足起不来 ⇒ 没有第二个"已有 key 的环境"。

**因此这一段验的是「接线与界面」，不是「模型理解」**：目标模式口令 → 引擎加注 → 模型调 `update_plan(goal)` → 立状/立目标 → 每步对照 → 收口。**模型能不能自己想明白目标，是另一件事，本段没有验。**
