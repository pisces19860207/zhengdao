### 判据④ 三档之外映射写死、计入 unknown、不许丢弃 —— **DONE**

规则在 `tools/eval-adapter.py` 顶部三张表（`TIER_EXACT` / `TIER_MARKERS` / `MIN_ROUND_CHARS`），**写死、不外接、不按 item 变**。
匹配三步：① 整条归一化后命中本名/别名 ⇒ `exact`；② 否则扫**最靠先出现**的档内标记，同起点取更长标记（这样 `不一致` 归矛盾而不是支持）⇒ `marker`；③ 三档之外 ⇒ `未知`，理由记 `off-tier`。
`--mapping-report` 出计数，`raw` 保留原文，每行还带 `mapping:{via,marker}` 便于人查。

全 100 条对账（真轮那一份）：

```

三档分布 {'支持': 17, '矛盾': 33, '未知': 50} 和 = 100      ← 一条不丢
三档之外（off-tier）17 条 ⇒ 全落 verdict=未知：True
映射来源计数 {'exact': 32, 'marker': 51, 'off_tier': 17, 'empty': 0, 'no_answer': 0}
```

自检覆盖（`--selftest` T01–T12）：`无法判断`→未知、`UNKNOWN`→未知、`也许吧`→未知且标 off-tier、
`不一致`→矛盾（长标记优先）、`矛盾：归属错置`→矛盾、`支持——与原文对齐`→支持、先出现者优先、空串与非字符串不炸。

**与「不代答」的分界**（这是口径边界，写清楚）：判据④管的是**答了但落在三档之外** ⇒ 计 unknown 不丢；
