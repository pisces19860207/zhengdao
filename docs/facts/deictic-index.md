> 状态：**教材级命名＋用户口述位置**（reality=real）。机器真源＝`deictic-index.json`（`deictic-index/v1`，2026-11-19）。
> 13 区定义沿用 `anatomy-zones.json`（单一真源，本索引不复制区表）；顺序链取 731 更正版。
> **改本文件必须与 `deictic-index.json` 同一提交一起改（双真相不许漂）**，同 `anatomy-zones` 的规矩。
> 用途：把"你指哪儿"查成"它叫什么"——人只能说位置、不知道名字时，把位置描述变成检索钥匙。

## 一、做什么 / 不做

```
做：① 位置口语→术语（正向，给人用）  ② 术语→位置描述＋关系链（反向，给引擎用）
    ③ 别名分层：规范名 / 口语 / 民间别名  ④ 触觉索引（触点×动作×手感四维→部位）
不做：功能解释（归 658/730/735）；对象与物件；行为指导；诊断性触诊结论（728 红线）。
与 669 分工：669 管"写错什么"，本单管"叫什么、在哪"。
```

## 二、别名分层与规范输出

| 层 | 用途 | 例（meatus） |
| --- | --- | --- |
| 规范名 canonical | **规范输出只用这一层** | meatus / 尿道口 |
| 口语 colloquial | 解释里可出现，可作检索钥匙 | 撒尿的那个眼、头尖上那道裂缝 |
| 民间别名 folk | **只进词表，不进规范输出** | 马眼 |

民间别名全集：meatus「马眼」、scrotum「囊袋」、testis「蛋蛋」。
`canonicalOf("马眼") == "meatus"`；规范输出恒为 `meatus（尿道口）` 形式，绝不含民间别名（单测断言）。

## 四、顺序链（反向查询的骨架，取 731 更正版）

```
apex 顶端 →【龟头坡 glansbody】→ corona 冠 → sulcus 冠状沟 →【颈部过渡 neckTaper】→ shaft 柱身
                                      ↑ 腹侧 frenulum 系带落在这里
                               prepuce 包皮覆盖范围跨 corona / sulcus
```

- 两个"坡"不混：龟头坡在 apex→corona（决定头型），颈部过渡在 corona→shaft（决定冠下收腰）。
- `apex / glansbody / neckTaper` 是链上**锚点**（anchor），host 分别指向 glans / glans / shaft，**不是独立分区**（13 区不变）。
- 完整链序（含两端分区）：`meatus → apex → glansbody → corona → sulcus → neckTaper → shaft → radix`。
- `chainOf("corona").prev=glansbody, next=sulcus`；`chainOf("sulcus").prev=corona, next=neckTaper`；相邻含链邻居＋侧挂反引。

## 五、正向匹配与歧义口径

- 闭集词面匹配：输入的文字包含某条描述的检索钥匙即命中该区，按命中数降序、表序升序排候选。零模型、零随机。
- **明确描述**（唯一命中）⇒ 直接出规范名。
- **歧义**（多区命中）⇒ 列全部候选 + 给区分办法，**不许硬选一个**。三条预置消歧：

| 易混区 | 区分办法 |
| --- | --- |
| sulcus / prepuce | 冠后一道环形凹沟=sulcus；能翻动、可滑移的一层薄皮=prepuce |
| scrotum / testis | 外层有褶皱、随温度松紧的囊=scrotum；里面卵圆、可单独滑动的内容物=testis |
| raphe / frenulum | 延伸到阴囊、不随牵拉改变的中线=raphe；连着包皮、牵拉敏感的小褶=frenulum |

## 六、触觉索引（第二索引）

三件齐：**触点** × **动作** × **手感四维**——缺一拒判（"软"不能指任何地方）。

- 触点闭集：指尖 / 指腹 / 指侧 / 掌根 / 手背
- 动作闭集：按 / 摸 / 搓 / 捏 / 转 / 托 / 滑
- 手感四维（各档位闭集）：
  - 软硬 firmness：很软 / 软 / 有韧性 / 硬
  - 弹性 elasticity：一按即回 / 慢回 / 压下去不回
  - 滑涩 glide：干涩 / 微涩 / 顺滑 / 湿滑
  - 温凉 warmth：偏凉 / 体温 / 偏热

| 规则 | 触点 | 动作 | 手感 | 强特征 | ⇒ 部位 |
| --- | --- | --- | --- | --- | --- |
| TACT-01 | 指腹/指尖 | 按 | 软或有韧性·一按即回 | 边缘有台阶/一道棱 | corona / sulcus |
| TACT-02 | 指尖/指腹 | 捏/滑 | 顺滑或湿滑 | 薄皮/能滑动 | prepuce |
| TACT-03 | 掌根/指腹 | 托 | 偏凉 | 有重量/褶皱 | scrotum |
| TACT-04 | 指腹/指尖 | 摸/捏 | 有韧性·顺滑 | 卵圆/椭圆形 | testis |
| TACT-05 | 指侧/指腹 | 滑/摸 | （不限） | 细管/条索 | cord |
| TACT-06（兜底） | 指腹 | 按/摸 | 软 | 无 | scrotum / glans（歧义，给区分动作） |

**判别优先级**：`requiresFeature=true` 的强特征规则优先；仅当没有任何强特征规则命中时，兜底规则 TACT-06 才生效——否则"一按即回+边缘台阶"会被"软"兜底污染成四区歧义。手感只写"摸起来怎样"，出现"病变/异常"诊断词一律不进输出（728 红线）。
