# 形轨 · 轮廓可见度阈值表（666）

> 状态：**作者裁定**（2026-11-16，卯五批）。物理依据来自《男性素材-事实底盘》十二节
> 与参考实现 `证道设计报告/附件-轮廓模型/silhouette_model.py`（照翻成 Kotlin，未重新
> 设计）。阈值不是文献实测，是作者的工程裁定；**改阈值必须本文件与
> `SilhouetteThresholds.DEFAULT` 同一提交一起改**（双真相不许漂）。

## 一、比值与四档

```
r     = H / C_eff
H     = 凸起高度（cm，来自形轨高度场；本批用夹具）
C_eff = C × 姿态张紧系数
C     = 面料弯曲长度（cm，实测表，ASTM D1388 / BS 3356 / ISO 4674-2）
```

| r 区间 | 档 | 判读词 |
| --- | --- | --- |
| r < 0.5 | 一档 | 隐藏 |
| 0.5 ≤ r < 1.2 | 二档 | 隐约 |
| 1.2 ≤ r < 2.0 | 三档 | 可见 |
| r ≥ 2.0 | 四档 | 明显 |

边界口径：**左闭右开，恰好压线归入更高档**（r=0.5 → 隐约、r=1.2 → 可见、r=2.0 → 明显）。
判据①的六点（0.49 / 0.5 / 1.19 / 1.2 / 1.99 / 2.0）就是照这张表钉的。

## 二、三态

| 态 | 何时 | 一句话 |
| --- | --- | --- |
| GRADED | 面料在表、阈值表完整 | `{面料}，凸起{H}mm ⇒ {判读词}（{位置}·{姿态}）` |
| REFUSED_NO_FABRIC | 面料不在实测表 | `面料「…」无实测 C，拒绝判读` |
| REFUSED_NO_THRESHOLD | 阈值缺失/非法 | `阈值表缺失，拒绝判读（fail-closed）` |

一句话硬规矩（判据⑤）：**≤40 字；不出现「大概 / 可能 / 也许」**——模型要么给档，要么
明说拒绝，不输出含糊话。

## 三、姿态张紧系数（作者裁定）

| 姿态 | 系数 | 依据 |
| --- | --- | --- |
| 站 | 1.0 | 基准 |
| 坐 | 0.85 | 设计报告 12.6：坐时布料张力升，C_eff×0.85 |
| 蹲 | 0.85 | 与坐同档处理（作者裁定）：蹲同样绷紧臀裆布料 |

判据④的确定性来源就是这个系数：同 H、同面料下，坐/蹲的 r 是站姿的 1/0.85≈1.18 倍，
可能跨档；方向由姿态标签唯一决定，不掺随机。

## 四、位置标签

腰线 / 裆缝 / 大腿根：**只进一句话（给读数定位），不进比值**。朝向（贴腹上行/水平前伸/
向下贴腿）与侧偏（正中/偏左/偏右）属状态内核，不在本单边界内。

## 五、面料 C 实测表（真源：`FabricSpec.ALL`）

| 面料 | C (cm) | 来源 |
| --- | --- | --- |
| 雪纺/真丝薄料 | 1.2 | 实测 ASTM D1388（区间 1.0–1.5，取 1.2） |
| 针织内裤(棉) | 2.0 | 工程取值 ○（针织普遍偏软，未查到成衣实测） |
| 棉衬衫布 | 2.5 | 实测 ASTM D1388（区间 2.1–3.5，取 2.5） |
| 7.5oz卡其 | 2.9 | 实测 ASTM D1388 |
| 10oz斜纹 | 4.4 | 实测 ASTM D1388 |
| 12oz牛仔 | 5.2 | 实测 ASTM D1388（牛仔整体 5–8，取 5.2） |
| 厚帆布 | 11.0 | 实测 BS 3356（区间 8–15，取 11.0） |

**表里没有的面料 ⇒ 明确拒绝**（判据⑥）。拒绝是结构性的：`FabricSpec` 构造私有，
调用方没有「自填 C=5」的路径，只能给名字查表；查不到返回 null ⇒ REFUSED_NO_FABRIC。

## 六、fail-closed（判据⑦）

阈值表任何一条缺失、非有限数、非正数或不严格递增 ⇒ `isComplete()=false` ⇒
**拒绝判读**，不许回落到任何默认档（尤其不许默认可见）。拒绝优先于猜。

## 七、方向更正记录（判据③）

派工单判据③原文「面料更挺括（C 大）⇒ 更易显」与参考实现及设计文档相反：
r = H/C 里 C 在分母，C 大（挺括）⇒ r 小 ⇒ **更难显**。参考实现表一实跑数据同向：
雪纺（C=1.2）顶起，厚帆布（C=11）几乎看不出。本单按参考实现的物理方向实现并单测
（**挺括面料永不进档**），派工单该句按笔误处理。
