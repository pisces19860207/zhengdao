# 交付自查三步（873）

> 适用：所有带“结果正确性”判据的交付。三步是**合取门**：少一步，报告不合格；测试绿不代替其中任何一步。
>
> 来源：835 因果链交付时，60 例全绿仍打印出“伤好了步态仍是 L5·L1”“汗只退一档”两处语义断尾；同轮变异还暴露了“夹具落错侧”和“断言拿常量自证”。本清单把那四处缺口写死。

## 0. 名词与硬判据

- **完整输出**：业务函数实际产出的整段文本/结构，包含头尾、单位和全部关键字段；不是 `assertEquals` 日志，也不是只截一张图。
- **独立预期值**：来自需求、外部规格、独立夹具或另一个真实来源；**不许**来自被测实现正在使用的同一个常量。
- **门槛两侧**：以判据定义的接受条件为准，分别取“最近的可接受值”和“最近的可拒绝值”。离散档位取相邻档；时间门槛取“到期时刻”和“到期前最近时刻”。
- **硬判据**：交付报告必须能定位到 ①至少 3 条完整输出及人读记录；②每条关键判据的双侧变异实际读数；③每条夹具的门槛、侧别、距离和实际输入。缺任一项 ⇒ 退回，不销账。

## 1. 第一步：把输出真读一遍

### 1.1 先跑，再把完整输出原样打印出来

在仓库根目录执行。`TEST_CLASS` 换成本条关键链路自己的测试类；不要用 `*` 把全仓输出混在一起。

测试里要打印的是业务结果本身。例如：

```kotlin
val state = CausalReplay.of(CausalScenarios.injuryChain()).at(Span825.CROSS_DAY)
println(CausalRenderer.render(state))
```

只写 `println("测试通过")`、只打印 `expected=3`、或让断言库截断长字符串，都不算完整输出。

### 1.2 人读后必须落成表，不能只写“合理”

| 输出 | 用例/命令 | 完整输出中的关键观测 | 独立预期 | 预期来源 | 人读结论 |
|---|---|---|---|---|---|
| 1 | `<测试名>` | `<原样抄数值/档位/头尾>` | `<数值或状态>` | `<需求条款/规格文件:行/独立夹具>` | `<一致/矛盾/缺字段>` |
| 2 | `<测试名>` | `<原样抄数值/档位/头尾>` | `<数值或状态>` | `<来源>` | `<结论>` |
| 3 | `<测试名>` | `<原样抄数值/档位/头尾>` | `<数值或状态>` | `<来源>` | `<结论>` |

人读必须逐项回答：

1. **数值**：是否在该字段定义的区间/档位内；单位是否与来源一致。
2. **终态**：到期后是否真的回到规格要求的终态，而不是只退一档、停在中间态或沿用受伤态。
3. **一致性**：同一结果里的相关字段是否互相矛盾；例如“伤情=无”却“步态=患侧 L5·L1”。
4. **断尾**：完整输出的首尾标记是否都在；最后一个必需字段是否存在；有没有被省略号、截断或半句话切掉。

不合格写法：`注意合理性`、`看起来正常`、`测试绿`。合格写法必须能指到上面的具体观测和来源。

## 2. 第二步：变异必须双侧都咬

### 2.1 先钉独立预期，再改实现

每条关键判据在变异前先写两行：

```text
判据：<例如“跨日后关节角必须回到 725 中位档 3”>
预期来源：<例如“725 中位档规格；不是 CausalRules.NEUTRAL_JOINT 的自引用”>
```

下面这种断言不算独立预期：

```kotlin
assertEquals(CausalRules.NEUTRAL_JOINT, state.level(CausalDim.POSE_JOINT))
```

它只能证明“回到了实现自己 named neutral 的值”，不能证明那个值就是规格要求的 3。正式证据要写独立字面量或独立配置，并注明来源：

```kotlin
assertEquals("725 中位档规格要求 L3", 3, state.level(CausalDim.POSE_JOINT))
```

### 2.2 每条判据做两个变异

| 侧 | 取值 | 预期 | 用途 |
|---|---|---|---|
| 可接受侧 | 门槛上的最近可接受值；实现可改成等价的独立字面量 | 绿 | 证明断言没有绑死某一种实现，且边界值确实放行 |
| 可拒绝侧 | 门槛另一侧的最近可拒绝值；或删掉关键恢复逻辑 | 红 | 证明断言真能拦住错结果 |

双侧变异表必须逐条回填：

| 判据 | 独立预期/来源 | 可接受侧变异 | 实际结果 | 可拒绝侧变异 | 实际结果 | 结论 |
|---|---|---|---|---|---|---|
| `<判据>` | `<值+来源>` | `<精确文件:行、old→new>` | `<绿/红+退出码>` | `<精确文件:行、old→new>` | `<红/绿+退出码>` | `<通过/无效>` |

判定规则：

- 可接受侧红 ⇒ 变异无效，先查夹具和预期是否绑死实现。
- 可拒绝侧绿 ⇒ 断言没牙，判据不成立。
- 编译失败不算“被断言拦住”；必须修到编译有效，再让目标断言红。
- 每个变异都要打印改了哪个文件、哪一段，并在结束后证明文件字节恢复原样。第 6 节给了可直接执行的 835 四枪脚本。

## 3. 第三步：夹具必须落在门槛正确一侧

### 3.1 每条夹具先登记，再调用

| 夹具 | 实际输入 | 门槛 | 侧别 | 离门槛多远 | 预期结果 | 用途 |
|---|---|---|---|---|---|---|
| `<id>` | `<完整入参/事件/时间>` | `<接受条件>` | 可接受 | `<等于/+1档/到期时刻>` | `<通过>` | 正例 |
| `<id>` | `<完整入参/事件/时间>` | `<同一门槛>` | 可拒绝 | `<−1档/到期前最近时刻>` | `<拒绝>` | 负例 |
| `<id>` | `<缺字段/空集合/非法档>` | `<同一门槛>` | 可拒绝 | `<明确缺失，不填默认值>` | `<拒绝或 absent(reason)>` | 缺省负例 |

“两侧都要有”指**同一条判据**必须同时有可接受与可拒绝夹具；不能拿另一条判据的夹具凑数。

### 3.2 用真实入参打印侧别，不靠嘴说

测试调用前打印完整夹具，例如：

```kotlin
println("FIXTURE=gait-cross-day at=${Span825.CROSS_DAY} threshold=healSpan side=pass distance=0")
println("FIXTURE=gait-before-heal at=${Span825.MINUTES} threshold=healSpan side=fail distance=到期前")
```

随后用第一步的 XML 输出命令把这几行连同完整业务输出一起打印。报告里抄实际值，不接受只写“夹具在正确侧”。

835 的夹具与断言可直接定位：

```bash
nl -ba app/src/test/java/com/example/zhengdao/baopu/state/causal/CausalScenarios.kt | sed -n '56,83p'
nl -ba app/src/test/java/com/example/zhengdao/baopu/state/causal/CausalChainRunTest.kt | sed -n '48,64p;93,98p'
```

必须核对到：

- 受伤夹具是 `InjuryGrade.SWELL`、`PainGrade.STEADY`、`healSpan=CROSS_DAY`；分钟级是受伤态，跨日级是恢复终态。
- 环境夹具的湿态在分钟级仍为 3，小时级按 825「汗干」必须到 0；不能只有“小时级”一个夹具。

## 4. 835 反例 A：伤好了，步态却没复位

### 4.1 门槛与两侧夹具

| 项 | 可接受侧 | 可拒绝侧 |
|---|---|---|
| 时间 | `Span825.CROSS_DAY`，恰好到期 | `Span825.MINUTES`，到期前 |
| 关节角 | 3（725 中位档） | 5（患侧档仍在） |
| 重心 | 3（725 中位档） | 1（患侧档仍在） |
| 预期 | 伤情/疼痛/步态都恢复 | 伤情尚未恢复，步态保持受伤态 |

独立来源：725 中位档是 L3；806 零档是 L0。不能拿 `CausalRules.NEUTRAL_JOINT/NEUTRAL_COM` 反过来证明中位必须是 3。

### 4.2 反例与双侧变异

- **可接受侧变异**：把 `gaitAfter` 的两个恢复目标从 `CausalRules.NEUTRAL_JOINT/NEUTRAL_COM` 改成字面量 `3/3`。行为不变，测试必须绿；这证明断言没有绑死常量实现。
- **可拒绝侧变异**：删掉 `gaitAfter` 的 `delayed` 恢复项。跨日后步态仍是 L5·L1，`链一_跨日之后伤情疼痛与步态都回到无` 必须红。

复现后实际会先看到：伤情/疼痛已回 0，但关节角期望 3 实际 5；JUnit 在第一条断言处 fail-fast，因此重心那条“期望 3 实际 1”不会在本次 XML 中执行到，不能冒充已观测读数。若要分别证明两个维度，应把 `delayed` 拆成两次单维度删除分别复跑。完整命令见第 6 节。

## 5. 835 反例 B：汗只退一档，没有干透

### 5.1 门槛与两侧夹具

| 项 | 可接受侧 | 可拒绝侧 |
|---|---|---|
| 时间 | `Span825.HOURS`，恰好到期 | `Span825.MINUTES`，到期前 |
| 皮肤湿 | 0（806 零档，825「汗干」） | 2（只退一档）或 3（完全没退） |
| 预期 | 小时级干透 | 小时级仍潮湿 |

独立来源：825「小时级：汗干」＋806 皮肤湿零档。不能拿 `CausalDim.SKIN_WET.min` 的存在反过来证明“汗干”就是当前实现选的终态。

### 5.2 反例与双侧变异

- **可接受侧变异**：把 `wetAfter` 的恢复目标从 `CausalDim.SKIN_WET.min` 改成字面量 `0`。行为不变，测试必须绿。
- **可拒绝侧变异**：把恢复目标从 `CausalDim.SKIN_WET.min` 改成 `2`。小时级只退一档，`链二_小时级汗干透_分钟级不干` 必须红。

复现后应看到的关键失败读数是：分钟级仍为 3（正确），小时级期望 0 实际 2（错误）。完整命令见第 6 节。

## 6. 835 四枪一键复现（双侧变异）

在 `wt-873` 仓库根目录用 Git Bash 执行。新工作树若缺 `local.properties`，先从主仓复制 `../zhengdao/local.properties`（gitignored，只含本机 SDK 路径）。脚本先把 `CausalChainRunTest.kt` 的两处步态预期从实现常量改成独立字面量 `3`，再只临时改 `CausalChains.kt`；每枪后按原字节恢复，结束时恢复源文件与测试文件。两个目标文件任一已有未提交或已暂存改动时直接拒绝。每枪开跑前再核对基线；检测到并行改动就保留现场并报错，绝不覆盖别人的工作。共享构建槽默认等 30 分钟，本脚本显式延长到 180 分钟；不会抢占或清理他人槽位。

```bash

python - <<'PY'

import hashlib
import re
import subprocess
import xml.etree.ElementTree as ET

root = Path.cwd()
source = root / 'app/src/main/java/com/example/zhengdao/baopu/state/causal/CausalChains.kt'

if not source.is_file() or not test.is_file() or not lock.is_file():
    raise SystemExit('缺少源文件、测试文件或构建锁，拒绝复现')
if not (root / 'local.properties').is_file():
    raise SystemExit('缺少 local.properties；先从 ../zhengdao/local.properties 复制本机 SDK 配置')

def git_clean(*paths):
    return all(
        subprocess.run(cmd, cwd=root).returncode == 0
        for path in paths
        for cmd in (
            ['git', 'diff', '--quiet', '--', str(path)],

test_text = test_baseline.decode('utf-8')
if ('\r\n' in source_text) != ('\r\n' in test_text):

def bytes_with_newline(text):

print('源文件基线 SHA-256 =', hashlib.sha256(source_baseline).hexdigest())

expected_old = '''        assertEquals("关节角回到 725 的中位档", CausalRules.NEUTRAL_JOINT, state.level(CausalDim.POSE_JOINT))

gait_old = '''            delayed = listOf(

                DelayedGrade(GradeWrite.to(CausalDim.POSE_COM, CausalRules.NEUTRAL_COM), healSpan),

gait_pass = '''            delayed = listOf(
                DelayedGrade(GradeWrite.to(CausalDim.POSE_JOINT, 3), healSpan),
                DelayedGrade(GradeWrite.to(CausalDim.POSE_COM, 3), healSpan),

gait_fail = '            delayed = emptyList(),'

sweat_pass = '        delayed = listOf(DelayedGrade(GradeWrite.to(CausalDim.SKIN_WET, 0), drySpan)),'
sweat_fail = '        delayed = listOf(DelayedGrade(GradeWrite.to(CausalDim.SKIN_WET, 2), drySpan)),'

expected_new_bytes = bytes_with_newline(expected_new)
if test_baseline.count(expected_old_bytes) != 1:
    raise SystemExit('步态断言锚点不是唯一一处，拒绝猜测')

test.write_bytes(test_independent)

        mutated = source_baseline.replace(old_bytes, new_bytes, 1)

        if source.read_bytes() != source_baseline:
            raise SystemExit(f'{name} 开跑前源文件已被并行改动，拒绝覆盖')
        if test.read_bytes() != test_independent:
            raise SystemExit(f'{name} 开跑前独立预期已被并行改动，拒绝覆盖')
        before_xml = xml.stat().st_mtime_ns if xml.exists() else 0

        print(f'\n===== {name}：已写入唯一变异（测试保持独立预期） =====')
        try:
            run_arg = f':app:testDebugUnitTest --tests "{test_class}"'

            restore_source(mutated)

        after_xml = xml.stat().st_mtime_ns if xml.exists() else 0
        if after_xml <= before_xml:
            raise SystemExit(f'{name} 没有生成新 XML，本轮读数无效')
        target = None
        for case in ET.parse(xml).getroot().findall('testcase'):
            if case.get('name') == target_test:
                target = case
                break
        if target is None:
            raise SystemExit(f'{name} 找不到目标用例 {target_test}')

        failure_text = '\n'.join((f.get('message') or f.text or '').strip() for f in failures)
        if expect_green:
            matched = result.returncode == 0 and not failures
        else:
            matched = result.returncode != 0 and bool(failures)
            for expected, actual in expected_readings:

                matched = matched and re.search(pattern, failure_text, re.IGNORECASE) is not None
        actual_green = not failures and result.returncode == 0
        print(f'{name}：退出码={result.returncode}，目标用例={"绿" if actual_green else "红"}')
        if failure_text:
            print(failure_text)
        if not matched:
            raise SystemExit(f'{name} 预期{"绿" if expect_green else "红"}，且红侧必须命中指定 expected/actual，但实际不符')
finally:
    current_test = test.read_bytes()
    if current_test == test_independent:
        test.write_bytes(test_baseline)
    elif current_test != test_baseline:
```
