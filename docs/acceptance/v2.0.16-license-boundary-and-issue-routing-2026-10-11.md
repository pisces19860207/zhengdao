## 五、追加：设置页「存储与缓存」标签竖排修复（用户当日复看后点出）

**用户原话**（2026-10-11）：「存储与缓存这几个字是竖着的，和其他的也不搭啊，修了这个就可以打了。」

**现象 / 根因**：设置入口页「环境」卡第一行标签**逐字换行、竖着排**。根因是
`ui/SettingsScreen.kt` 的两个共享行件把伸缩给了标签、没给值：
`internal fun SettingRow(label: String, value: String, valueColor: Color = Color.Unspecified, onClick: () -> Unit)`
（原 `:304-337`）与 `internal fun InfoRow(label: String, value: String)`（原 `:278-297`）——
`label` 带 `Modifier.weight(1f)`、`value` 裸奔；Compose 的 `Row` **先量无权重子项**，值按固有宽度占满
（真机实测 `rootfs 768 MB · home 3530 MB · cache 6 MB` 占 **x 112→1172 = 1060px**，整行可用宽约 1088px），
标签只剩 ≈0 宽。入口页只有这一行数值够长，所以只有它暴露。详见 ERRATA **E-111**。

**改法（最小改动）**：标签 `maxLines = 1` + `softWrap = false`（按固有宽度一行）；
标签与值之间加 `Spacer(Modifier.width(12.dp))`；值 `Modifier.weight(1f)` + `textAlign = TextAlign.End`
（新增 `import androidx.compose.ui.text.style.TextAlign`）。共享件修一处全修，
调用点含 `SettingsStorageActivity` / `SettingsDataActivity` / `SettingsKeepaliveActivity` / `SettingsAboutActivity`。

**真机复测（改后 `uiautomator` dump）**

- 入口页：`存储与缓存 :: [112,575][361,645]`（**单行**、宽 249px）；值
  `rootfs 768 MB · home 3530 MB · cache 6 MB :: [403,540][1161,680]`（**140px 高 = 两行**、右对齐）；
  下一行 `环境与更新 :: [112,780][361,850]` 单行。
- 二级页「存储与缓存」三行（`rootfs（系统层）` / `home（登录态与配置）` / `cache（下载缓存）`）与
  「关于」页各行（`版本` → `2.0.16 (versionCode 32)`、`版本来源` → `官方发布 ✓`、
