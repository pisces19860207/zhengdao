## 0. 一句话

第二十批已经能列会话、能开、能删，但真机一看有三处不对味：**轮数全显示 0**、**抽屉「资料库」名不副实**、**删掉正在聊的那个会话后的落点没定义**。本批把这三处修顺。

| # | 事实 | 证据 |
| --- | --- | --- |
| A | 会话库每行显示 **「0 轮」**，但那些会话明明聊过（`session.msg_count` 没维护） | 真机截图：`T`／`0 轮 · 16:21 · 已封卷`、`ping`／`0 轮 · 09:49 · 可继续` |
| B | 抽屉「资料库」desc 写「看搬进来的书、整理进度与导出记录」，落点却是终端设置页 | `ui/baopu/BaopuDrawer.kt` 的 desc + `onLibrary` 落到 `openSettings`（第二十批没改这条） |

## 2. 规格

### 2.1 A 段 · 轮数要真

- **不改表结构**（`msg_count` 留着不动，避免迁移）：会话库的查询直接数出来——
  `LEFT JOIN (SELECT session_id, COUNT(*) AS n FROM message GROUP BY session_id)`，或列表里对每条 `SELECT COUNT(*)`（会话最多几十条，N+1 可接受；**选哪种写清理由**）。
- 轮数**口径**：只数 `message.role='user'` 的条数（「一轮」＝用户一次发话），与抱朴对话区「轮」的概念对齐；
- 列表文案改成「N 轮 · HH:mm · 已封卷/可继续」不变，只把 N 变真；**旧会话 0 轮真为 0 时照实显示 0**，不许凑数。

### 2.2 B 段 · 抽屉「资料库」说真话

二选一（**本批只允许改文案，不做真资料库页**——那是刀 2）：
- desc 改成当前实情，例如「终端与资料（书单与导出记录还在做）」，**不许**再承诺没有的东西；
- 或者把这一项**改成两个**：`设置`（现落点）＋ 删掉「资料库」这一项，等刀 2 再加回来。
两种都要在报告里写清选了哪个、为什么。

### 2.3 C 段 · 删掉当前会话之后的落点

- 删的**不是**当前会话 ⇒ 只刷新列表，当前会话不变；
- 删的**正是**当前会话 ⇒ 依次：`controller.sessionId = null` → 视图清空（与「新会话」同样的清空动作，但**不**触发封卷）→ 回到空态「还没有对话」→ 列表刷新；Toast 或一行提示「已删除，当前回到空态」；
- **不许**在删除后自动跳到另一个会话（用户没选，别替他选）。
